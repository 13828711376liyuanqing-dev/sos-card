GR5526 固件检查与授权签名工具  Gr5526Tool.exe  v1.1 使用说明
==========================================================

【2026-11-04 起】
  - GR 签名镜像（正文 + 904）OTA 红线 393216 字节（384 KiB）：超过就报错、不签名，因为整机 OTA 时 CAT1 文件区放不下；
    超过 376832 提醒。这条比 GR 槽（441464）严得多，以它为准。
  - 红线数字在工具包根目录的 budget.json（所有工具和一键工具共用，只改这一个文件，并写明日期和原因）；没有这个文件时用内置的 2026-11-04 默认值。说明见 doc/2026-11-04_OTA空间红线_GR与CAT1大小管控.md。

一、这个工具做什么
  对编译好的 GR5526 应用固件（.hex 或 .bin）做检查，再用你选择的密钥签名，得到可以交给 OTA 打包工具的“签名镜像”。
  只看文件，不关心用什么编译器生成（Keil、GCC 都行）。签名镜像不是直接烧录用的镜像（没有 Boot 配对）。
  什么时候用：每次编译出新的 GR 固件，要做 OTA 之前。
  运行环境：Windows 10/11，不用安装任何软件；整个文件夹（含 contracts）放在一起。不依赖 Luatools。
  私钥不在工具里：签名时由你选择，工具只在临时目录放一份，签完立即覆写删除。

二、固件文件怎么得到
  Keil：F7 编译后在 Objects 目录里得到 YP001_GR5526.hex。
  GCC：用 objcopy 导出，二选一：
        arm-none-eabi-objcopy -O ihex   app.elf app.hex
        arm-none-eabi-objcopy -O binary app.elf app.bin      （bin 的第一个字节必须对应应用起始地址 0x00202000）
  工具不接受 ELF/AXF 文件，也不管你是怎么编译的，只检查导出来的 hex/bin 内容。

三、窗口里要选的四项
  ┌ 1. 固件文件 (.hex / .bin)
  │  例子：  D:\CODEX\sos-card\firmware_releases\...\Objects\YP001_GR5526.hex
  │  作用：  要检查、签名的固件。它里面必须有且只有一个版本标记 YP001_FW|GR5526|001.005.003|7|END，
  │          工具据此知道这是 1.5.3 版、build 7。同时检查：HEX 校验和与地址范围（必须在 0x00202000 起的应用区，不碰
  │          Boot/SCA/NVDS）、向量表、大小（正文 ≤ 441464 字节）。已经带签名的 .bin 不能再次签名。
  │
  ├ 2. 期望版本（可选）
  │  例子：  1.5.3
  │  作用：  固件里的版本标记必须就是它，否则拒绝。防止拿了旧固件或忘了重新编译就去签名。
  │  留空：  不核对（签名后文件名里的版本来自固件本身，可以自己对一下）。
  │
  ├ 3. 私钥文件 (.key)
  │  怎么选：点“选择…”，选私钥文件本身（不用选公钥，工具从私钥里自动导出公钥）。
  │  例子：  D:\keys\OTA_TEST_PRIVATE.key
  │  作用：  用私钥给固件签名；签完立即用它导出的公钥验签，公钥指纹写进签名镜像。选到不是私钥的文件会提示“私钥文件无效”。
  │          设备只认它信任的那把公钥对应的签名：用错了密钥，镜像会被设备拒绝。
  │  只有“检查并签名”需要；“检查”不需要。
  │
  └ 4. 输出位置
     例子：  D:\out\gr_1.5.3
     作用：  签名结果放在这里，BIN 和 HEX 各一份（内容相同）：
             GR5526_1.5.3_b7_signed.bin 和 GR5526_1.5.3_b7_signed.hex（交给 OTA 打包工具的用 BIN 或 HEX 都行；HEX 方便给下载工具/J-Link 用）
             再加
             GR5526_1.5.3_b7_signed_record.json（签名记录：输入和输出文件的 sha256、公钥指纹、合同 sha256、版本）。
     已有同名文件时：会弹窗问“要用这次的结果替换它吗？”，选“是”才替换。

  不用选的东西（工具自己处理）：布局合同和数据合同用工具文件夹里的 contracts（它们的 sha256 会写进签名头，设备按它核对分区布局和
  用户数据保护范围，所以不能随意换）；输出固定为 BIN 和 HEX 两份。

四、两个按钮
  检查：只做检查，不签名、不写文件、不需要密钥。每次编译完先点它。
  检查并签名：检查全部通过后签名，签完立即验签，写出的文件回读核对。任何 ERROR 都不会输出文件。

五、报告怎么看
  OK = 通过；WARN = 提醒；ERROR = 必须处理（没有输出）。
  “正文已用到 99% 的槽，后续版本增长空间很小”   WARN：固件快把 441464 字节的槽填满了，再长就放不下了。
  “HEX/BIN 共 … 字节，超过上限 441464 字节 … 字节”   ERROR：固件太大放不进 GR 的升级槽。HEX 的大小按“最高地址 − 0x00202000 + 1”算
                                                   （不是 HEX 文件本身的字节数）。报告会写出实际大小、上限和超出多少字节；要减小固件（去掉功能/库、
                                                   优化选项）后重新编译。快到上限（超过 95%）时只给 WARN，OK 行里会写“余多少字节”。
  “HEX 里有应用区之前的数据”                      ERROR：HEX 里夹带了 Boot/SCA/NVDS 区的数据，要导出只含应用的 HEX。
  “固件里的版本是 … 与期望的 … 不符”             要重新设置源码里的版本并重新编译，不能只改文件名。
  “GR 地址越界 / HEX 重叠 / 校验和错误”           HEX 文件有问题或包含了 Boot/NVDS 区的内容，检查编译输出和链接脚本。
  “私钥与固定公钥不匹配”                         （命令行同时给了 --public 时）私钥和公钥不是一对。
  “已经是带签名尾部的镜像，不能再次签名”         选成了上一次的签名结果。
  “找不到私钥文件 / 公钥文件”                   没选私钥文件，或选的文件不是私钥。

六、完整例子：签出 1.5.3 的 GR 镜像
  1. Keil 编译（或 GCC 导出）得到 YP001_GR5526.hex，源码里版本已是 1.5.3、build 7。
  2. 固件文件选这个 hex；期望版本填 1.5.3；点“检查”→ 通过。
  3. 私钥文件选 D:\keys\OTA_TEST_PRIVATE.key；输出位置选 D:\out\gr_1.5.3；点“检查并签名”。
  4. 得到 D:\out\gr_1.5.3\GR5526_1.5.3_b7_signed.bin 和 .hex，把它交给“3_整机OTA打包”工具。

七、命令行（窗口里没有的选项只在这里）
  Gr5526Tool.exe check  <文件> [--expect-version V] [--prev <文件>] [--pair <文件>]
      --prev  上一版固件（hex、bin 或已签名 bin）：检查版本递增、build 变大    --pair  同一固件的另一种格式：互相比对内容
  Gr5526Tool.exe sign   <文件> --out <目录> --private <私钥> [--public <公钥>] [--layout <json>] [--data <json>] [--format bin|hex|both]
                        [--expect-version V] [--prev <文件>] [--pair <文件>] [--force]
  Gr5526Tool.exe verify <已签名bin或hex> --public <公钥> [--layout <json>] [--data <json>] [--pin <公钥sha256指纹>]
      验证已签名镜像的签名、公钥、合同和正文摘要（OTA 打包工具打包时也会验证 GR 镜像）
  Gr5526Tool.exe --version
  例子：Gr5526Tool.exe sign app.hex --out D:\out\gr --private D:\keys\OTA_TEST_PRIVATE.key --expect-version 1.5.3
  返回值：0 通过；1 有错误；2 参数错误。

八、检查项汇总
  - 只接受 .hex / .bin；HEX 的记录长度、校验和、EOF、地址范围；向量表（栈指针、复位入口）符合 A 槽和 RAM 布局；
  - 应用正文 ≤ 441464 字节（442368 字节槽减去 904 字节签名尾部）；
  - 有且仅有一个 YP001_FW|GR5526|版本|build|END 标记；期望版本；
  - 输入不能已经带签名；私钥是 RSA2048（公钥由它导出）；布局/数据合同存在；
  - 签名后立即做原生 PSS 验签；写出的每个文件回读核对。

九、版本
  Gr5526Tool.exe --version 显示工具版本。本工具不依赖 Luatools，Luatools 升级与它无关。
