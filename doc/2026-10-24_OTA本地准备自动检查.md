# OTA 本地准备自动检查

SAM | 2026-10-24 +08:00 | 将前轮冻结资料核对变成可执行检查，避免缺设备证据时误报实板成功。只检查本地材料，不连接或控制设备。

## 使用

在项目根目录运行（普通Python 3.9及以上，无第三方依赖）：

```powershell
python tools/ota/check_lab_preparation.py
```

本机已验证运行时：

```powershell
& 'C:/Users/SamLi/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe' tools/ota/check_lab_preparation.py
```

默认只读 `logs/ota_lab_preparation_20261024/source_data_map.json` 和 `device_cases.json`，以及清单内源码。可用 `--preparation` 指定另一组同结构的准备目录。工具不生成/更新基线，不改设备门禁，不执行网络、串口、下载或擦除。

## 行为

| 检查 | 结果处理 |
|---|---|
| 冻结源码内容变化、缺失或新增根目录Lua | 资料检查失败，报告变化；不自动覆盖冻结指纹 |
| 8项用例缺失、重复、输入结构错误 | 资料检查失败 |
| 准备表被填成PASS或塞入未经此工具验证的设备证据 | 拒绝为其背书，报告DEVICE_CLAIM_NOT_VALIDATED |
| 把未知KV当空库、宣称已经操作设备或开放生产安装 | 准备范围不符，检查失败 |
| 来源路径越界、绝对路径、重复路径或非法hash | 拒绝读取 |
| 正确的未执行准备材料 | local_preparation_ok=true，但device_ota_accepted始终false |

退出0仅指准备材料格式和冻结内容有效，**不是实板通过或允许安装**。退出1指资料无效或变化。后续实际设备验收不通过将状态字段改成PASS完成，需独立核验原始设备证据；本工具不承担该能力。
