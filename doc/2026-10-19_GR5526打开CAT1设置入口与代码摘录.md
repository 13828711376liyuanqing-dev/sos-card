## 手工调试怎么用

在 GR 调试串口（默认 UART0 115200/8N1，Windows COM 号现场核对）输入：

```text
cat1_power status
cat1_power on
cat_baud 460800
cat_at AT_INFO
cat_at AT+ANTSTATUS
business status
```

以上是人工操作示例，本次未执行。`cat1_power on` 只请求供电。如果模块未启动，结合模块日志和电源状态，再执行一次 `cat1_power key`，当前代码按下约1600ms后释放。模块已运行时无需再按 PWRKEY。

`AT_INFO`、`AT+ANTSTATUS` 是当前 Lua 项目命令；`cat_diag AT` 的意义取决于 CAT1 正在运行原生 AT 固件还是 Lua 自定义解析，不能把没有原生 OK 当作电源故障。

int cat1_debug_power(int argc, char *argv[])
{
    if (argc != 2 || (strcmp(argv[1], "on") && strcmp(argv[1], "off") &&
                      strcmp(argv[1], "key") && strcmp(argv[1], "status"))) {
        cli_printf("Usage: cat1_power on|off|key|status\r\n"); return -1;
    }
    if (!strcmp(argv[1], "status")) {
        cli_printf("[CAT1 POWER] mode=power_only; UART is manual; VBAT unmeasured\r\n");
        return 0;
    }
    if (!yp001_ota_power_change_allowed()) {
        cli_printf("[OTA] power change denied: installation pending or journal unknown\r\n");
        return -1;
    }
    app_io_init_t pin = APP_IO_DEFAULT_CONFIG;
    pin.mode = APP_IO_MODE_OUTPUT;
    pin.pull = APP_IO_NOPULL;
    bool key = !strcmp(argv[1], "key");
    pin.pin = key ? YP001_CAT1_KEY_PIN : YP001_CAT1_POWER_PIN;
    pin.mux = key ? YP001_AON_GPIO_MUX : YP001_GPIO_GPIO_MUX;
    uint16_t ret = app_io_init(key ? YP001_CAT1_KEY_TYPE : YP001_CAT1_POWER_TYPE, &pin);
    if (ret) { cli_printf("[CAT1 POWER] gpio_init_error=0x%04X\r\n", ret); return -1; }
    if (key) {
        ret = app_io_write_pin(YP001_CAT1_KEY_TYPE, pin.pin, YP001_CAT1_KEY_ASSERT);
        if (!ret) delay_ms(1600);
        uint16_t release = app_io_write_pin(YP001_CAT1_KEY_TYPE, pin.pin, YP001_CAT1_KEY_RELEASE);
        if (!ret) ret = release;
        cli_printf("[CAT1 POWER] manual_key code=0x%04X; no AT sent\r\n", ret);
    } else {
        bool on = !strcmp(argv[1], "on");
        ret = app_io_write_pin(YP001_CAT1_POWER_TYPE, pin.pin,
                               on ? YP001_CAT1_POWER_ON : YP001_CAT1_POWER_OFF);
        cli_printf("[CAT1 POWER] rail_request=%s code=0x%04X; USB may supply VBAT; no AT sent\r\n", on ? "on" : "off", ret);
    }
    return ret == APP_DRV_SUCCESS ? 0 : -1;
}

## 运行时还要检查的门控

- `yp001_business_service()` 在出货断电锁定时直接返回；初始化尚未完成时也不执行。
- `QV_onIdle()` 在运动诊断独占期间、睡眠测试期间会提前返回，暂缓普通业务轮询。当前代码还会在 EPD BUSY 等待处调用业务服务，不能只看一处循环判断整机状态。
- 2026-10-19 的 UART 睡眠适配会在断 CAT1 电源前释放 UART4 为输入，以避免高电平反灌；恢复路径重建原 UART 所有者。要检查 `yp001_test_uart_pause()/resume()`，不要仅强制改复用或将 RX 设成输出。
- `yp001_ota_power_change_allowed()` 拒绝时不能绕过保护改电源；这是保护升级中的设备与用户数据。
