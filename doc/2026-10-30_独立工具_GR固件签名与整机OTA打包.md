## 一、GR5526 固件检查与签名（`tools/gr_release/GR5526_Tool/Gr5526Tool.exe`）

在 `gr_build_tool.py` 基础上拆出“只管文件”的部分。Keil 构建验收（build log、陈旧目标文件）和 J-Link 烧录仍在 Python 版里，其 `sign` 改为调用这个 exe，只剩一套签名实现（原来调用 `logs/` 里临时编译的 `GrBaselineSign_current.exe`，已不再使用）。

| 能力 | 内容 |
|---|---|
| 输入 | `.hex` 或 `.bin`，Keil 或 GCC（objcopy）生成均可；ELF/AXF 拒绝并提示先导出 |
| 检查 | HEX 记录长度/校验和/EOF/地址范围；向量表；应用正文 ≤ 441464 B（槽 442368 − 904 签名），≥95% 给警告；有且仅有一个 `YP001_FW\|GR5526\|版本\|build\|END`；期望版本；与上一版比较（版本递增、新版本 build 必须更大、同版本不能改 build）；HEX/BIN 内容互比；已带签名尾部的不能再签 |
| 授权签名 | 导入私钥、公钥、布局/数据合同（合同默认用文件夹自带的公开副本）；签名后立即原生 PSS 验签；输出 `GR5526_<版本>_b<build>_signed.bin/.hex` 和签名记录 json（输入/输出 sha256、公钥指纹、合同 sha256）；写出后回读核对；已有同名文件不覆盖 |
| 验证 | 已签名 bin/hex：签名、公钥块、合同、正文摘要；可用 `--pin` 固定公钥指纹 |
| 私钥 | 不在工具文件夹里；临时目录只放一份，签完覆写删除 |

实际结果：对 10-30 的 1.5.2/b6 固件，检查通过并给出 “正文已用到槽的 99%，只剩 3896 字节” 的警告；对 10-29 签出的 1.5.2 镜像验签通过。

## 二、整机 OTA 打包（`tools/ota/pack_tool/YpOtaPack_Tool/YpOtaPack.exe`）

在原有打包核心（`tools/ota/portable` 的 PackCore/BundleSigning/GrProjectNative/Cat1Native，已打出 1.5.1、1.5.2 两个实板包）之上做独立前端，窗口和命令行共用同一套检查。`luatools/` 子文件夹只含 6 个配套文件（luac、soc_tools、7z.exe/7z.dll、4 个厂商库源码），2.3 MB，程序按 sha256 校验。

| 命令 | 作用 |
|---|---|
| `cat1` | 从 Air780EGH 源码生成 CAT1 .sota 和 review.json：自动算源文件指纹，把 review 的 sha256 写进（暂存的）main.lua 的 evidence_sha256；main.lua 版本不是目标版本时拒绝 |
| `auth` | 生成签名授权文件：绑定 GR 正文、CAT1 包、review.json 的 sha256 和升级范围；“已评审”“Boot 已实板验证”必须显式确认 |
| `pack` | 检查并生成 `<前缀>_<源>---<目标>_<后缀>.zip`，列出包内文件大小和 sha256，输出整包 MD5/SHA-256 |
| `verify` | 验证已有升级包 |

检查：GR 镜像签名/合同/槽大小；CAT1 .sota 读回解压、脚本 ≤ 524288 B；review.json 内容；CAT1 空间（GR 暂存 + 保留放得下，余量 <4 KiB 警告）；压缩包 ≤ 2 MiB；授权文件签名、公钥一致、范围和 sha256 绑定；两端固件版本与授权目标一致；名称前缀/后缀只能字母数字下划线点、≤48、不含 `---`；同名文件拒绝覆盖；错误码翻译成中文原因（如 `FIRST_TRIAL_NOT_PROVISIONED`）。

**改动**：`PackCore.cs` 增加 `ExtraRanges`（运行时由已验签的授权文件放行版本范围），内置白名单不变。授权文件 = 评审记录 + RSA 签名（独立的域 `YP001_OTA_AUTHORIZATION_RSA_V1`），用来放行新范围而不用改程序重编译。

**一个实用发现**：10-29 打 1.5.2 包时我手填的 CAT1 可用空间是 495616，而设备清理前的真实可用只有 450560，GR 暂存包需要 454856，所以当晚卡在 `COMPONENT_SPACE`。新工具要求填 `cat_at OTA_FS` 的真实读数（可用 = (总块数 − 已用块数) × 4096），用 450560 打包会直接被拒绝（已复现）。
