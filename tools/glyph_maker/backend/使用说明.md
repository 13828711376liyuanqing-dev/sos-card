# 姓名字形生成器（后台版）使用说明

SAM | 2026-11-02 | 读者：平台/后台同事（不需要硬件，不需要安装任何软件）

## 它做什么

终端屏幕只自带约 280 个常用字。给居民显示姓名时，平台要把姓名里**每个字的点阵**一起发给终端。这个工具把姓名变成终端要的那条消息（`residentNameMsg` JSON），平台原样下发即可。

## 怎么用

1. 用 Chrome 或 Edge 打开 `姓名字形生成器_后台版.html`（双击即可，不联网也能用）。
2. 在"姓名"里输入名字。下方每个字会显示状态：
   - 绿色"字体"：已从字体生成，不用管。
   - 红色"字体没有，请描点"：电脑上的字体都没有这个字，见下面"难字"。
   - 蓝色"手绘"：用的是你画的点阵。
3. 右下"预览"是终端屏幕的样子（主页大字 32px、低电页小字 16px）。
4. 点"下载 residentNameMsg JSON"，把文件内容作为 MQTT 消息发到该终端的下行主题：`/iotplat/render3/WARNCARD3/<IMEI>/down_raw`。
   只用 JSON 文件上传/下发，不要压缩成 zip（终端不接受 zip）。
5. 终端回执在 `/iotplat/datapush3/notsos/WARNCARD3/<IMEI>`：`residentNameReply`，`Result` 为 `ok` 表示已显示；`fail/bad/stale` 表示失败、格式不对、Seq 比上一条旧。

## 难字怎么办（输入法打不出、字体里没有）

| 情况 | 做法 |
|---|---|
| 输入法打不出来 | 在"打不出来的字"里输入 Unicode 码点，点"插入"。支持 `U+20BB7`、`20BB7`、`&#x20BB7;`，多个用空格隔开。码点可以从户籍系统、身份证系统、或者网上的汉字查询网站查到 |
| 字体里没有（红色） | ① 先试"加载字体文件"，选一个含生僻字的字体（如花园明朝、思源宋体等）；② 还没有，就点这个字，在右边描点：输入一个**结构相近的参考字**（如"珺"参考"君"），会以灰色垫在底下，照着用鼠标左键画、右键擦，画好点"采用这个手绘字形"。32px 和 16px 各画一次 |
| 画好的字要给同事用 | "导出手绘字库"得到 `手绘字库.json`，同事"导入手绘字库"后同一个字自动用手绘版本 |

**生僻字发淡**：黑体里没有的字（多在扩展区）浏览器会借用宋体风格的扩展字体（如 SimSun-ExtB），笔画细，在黑白屏上显得淡。工具会**自动加粗**这类字（字块下方显示"加粗:自动 ✓"），点那个按钮可切换"自动 / 开 / 关"。

已测试：基本区汉字、扩展 B 区（如"𠮷"U+20BB7，Windows 自带的 SimSun-ExtB 字体里有）都能生成并在终端实板上正确显示。

## 规则（工具会自动检查）

- 姓名：**主页最多显示 5 个字**（汉字等非英文字符，英文不计个数），第 5 个之后自动截掉，只推这 5 个字的字形；UTF-8 ≤ 63 字节（2026-11-03 用户决定）；每个汉字 32px 和 16px 各一份。
- 园区：会随站点变（燕园、鹏园…），园区里的字也一起生成（16px），最多 11 个字。
- **姓名、房号、园区全部由后台下发，出厂本地不留，只留存放空间**（2026-11-04 用户确认）：姓名、园区里的每个非英文字都推字形，**不管设备自带字库有没有**；房号只用数字等，继续用设备自带字库，只推文字。英文名加空园区时字形是 0 个。
- 字形最多 28 个；**整套字形的存储大小 ≤ 4000 字节**（20 B 头 + 每个字形 16 B + 点阵；终端存在 GR 专用 Flash 两页 A/B，4 KB，2026-11-04）；5 字姓名 + 11 字园区实测约 1.4 KB，余量充足；超了工具会报错。
- **`Seq` = 生成时的当前时间（秒）**，每次生成自动刷新，不用填；设备只收比上一次大的 `Seq`。2026-11-04 起早于 2026-01-01 的 Seq 直接报错（第一个后台文件用了自动模式里写死的 2024 年值 1730600000）。"手动 Seq"只给台架测试。
- 房号只能用数字、字母和"号楼栋单元层室"（设备 28px 自带字库，房号不推字形），其他字直接报错。
- 批量 / 无界面生成：打开 `姓名字形生成器_后台版.html?auto=<姓名>&room=<房号>&campus=<园区>`，结果（JSON 或 `ERROR …`）写在页面 `#auto-out`；`&seq=` 可指定 Seq（不能早于 2026-01-01），不给就用当前时间。
- 房号不超过 63 字节、园区不超过 95 字节。

## 给要把它做进后台服务的同事

- 消息格式、点阵格式、CRC 算法都写在网页源码 `// CORE-BEGIN` 到 `// CORE-END` 之间，是纯 JavaScript 函数（`crc16`、`pack`、`b64`、`trim`、`glyphJson`、`buildMsg`），可以直接搬进 Node 服务；Python 版在 `tools/glyph_maker/glyphlib.py`，两者已逐项比对一致。
- 点阵：1 位/像素，每行补齐到整字节，高位在前；`X/Y` 是相对基线的偏移（`Y` 为字形底边在基线上方的行数，可为负）；`A` = 字号 × 16。
- `C` = CRC-16/CCITT-FALSE（多项式 0x1021，初值 0xFFFF），覆盖 `U(3 字节) S W H X Y A(2 字节)` 加点阵字节。
- 网页用浏览器渲染字体，和终端自带字相比位置可能差 1 像素；但终端对推送过来的字**全部用推送的字形**显示，所以同一个姓名内部是一致的。

## 不需要做的

不需要接终端、串口、刷机；不需要安装 Python/Node。终端侧的东西由硬件同事负责。
