## 交付与入口

在 PowerShell 运行以下命令。

```powershell
# 查找 C2
python D:\CODEX\sos-card\tools\c2_meter\c2_meter.py list

# 连续记录 60 秒，输出文件必须尚不存在

```

使用前退出 ATK-C。工具采用独占打开，避免两个读取者分走 USB 数据。存在多个 C2 时，用 `list` 返回的完整设备路径通过 `--device` 指定一台。

默认 USB 单次读取超时为 2000 ms，可用 `--timeout-ms` 指定。采集时长到期后退出，最后一次 USB 读取可能额外等待一个超时周期。Ctrl+C 退出会关闭设备和输出文件，已有记录保留。文件路径需指向已存在的父目录。

成功退出码为 0，连接、超时和文件错误为 1，Ctrl+C 为 130。错误 JSON 写入 stderr。AI 应检查退出码，超时或断线后重新执行命令取得新读数。

## 输出与 Python API

实际读取示例。

```json
{"timestamp_utc":"2026-11-12T16:05:32.293182+00:00","sample_index":3,"voltage_v":5.12055,"current_a":0.035,"current_ma":35.0,"power_w":0.17921925}
```

`timestamp_utc` 是主机收到该批 USB 数据时的 UTC 时间，北京时间加 8 小时。每个帧含四组样本，`sample_index` 为帧内 0～3。一次 USB 读取可能包含多帧，这些样本共享主机接收时间。设备端精确采样时刻与间隔尚未取得，分析短脉冲时保留该时间精度限制。

`voltage_v` 单位为 V，`current_a` 为 A，`current_ma` 为 mA，`power_w` 为对应电压与电流乘积。读数表示 C2 所在测量支路，使用时应在实验记录中填写接线位置。

AI 在项目根目录可调用以下 Python API。

```python
from tools.c2_meter.c2_meter import C2Meter

with C2Meter(timeout_ms=2000) as meter:
    samples = meter.read()
    latest = samples[-1]
    print(latest["voltage_v"], latest["current_ma"])
```

`read()` 返回本次接收的完整帧样本列表，失败抛出异常。用于长时间调试时在同一个 `with` 内反复读取，退出上下文释放 WinUSB 句柄。

### 数字平滑

每约 100 ms 汇总此窗口全部接收样本的均值，再计算基于真实主机时间间隔的指数移动平均。

```text
alpha = 1 - exp(-dt / tau)
display = previous + alpha * (window_mean - previous)
```

默认时间常数 `tau = 1 秒`，允许切换关闭、0.5 秒、1 秒和 2 秒。默认情况下阶跃响应约 1 秒到达变化量的 63%，约 3 秒到达 95%。关闭平滑时显示约 100 ms 窗口均值。数字与曲线共用显示平滑设置，CSV 逐样本保存原始接收值。瞬态峰值统计读取 CSV。
