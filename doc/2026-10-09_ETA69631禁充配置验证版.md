# ETA69631 禁充配置验证版

修改人：SAM；修改时间：2026-10-09 12:20 +08:00。

## 适用边界

这是用户确认的配置验证版，不是可接电池使用的正式充电固件。只接5 V，电池保持断开。nCE硬件接地、芯片默认CHG_CONFIG=1，软件无法消除上电到初始化执行前的默认充电窗口；芯片掉电重启或I²C失联也不能靠软件保证禁充。不得把“函数返回成功”理解为物理电流已验证。

电池依据：爱温思科技 YQ_452435-530mAh3.8V(DAM)承认书第4、8页：530mAh、标准106mA、最大265mA、限制电压4.35V、终止10.6mA、充电0～45℃、NTC 10kΩ/B3435/5%。本版选择较低的100mA/4.20V验证配置。ETA69631最小终止电流20mA不同于10.6mA，不能声称符合标准充满曲线；NTC与板上R62并联及45℃截止仍待解决。

## 核验值与顺序

| 寄存器字段 | 预期 |
|---|---|
| REG01[4]/[5] | CHG_EN=0、OTG=0（不主动开启/切换OTG；遇OTG已开时配置失败） |
| REG00[4:0] | 0x04，即IIN=500mA；其余位保留 |
| REG02 | 0x05，即ICHG=100mA |
| REG03 | 0x00，即IPRE=20mA、ITERM=20mA |
| REG04[7:2] | 0x0D，即VREG=4200mV；其余位保留 |
| REG0D[7] | 0，关闭+5mV微调，其余位保留 |
| REG05 & 0xB8 | 0x88，即WD=0、EN_TIMER=1、EN_TERM=1；安全计时长度及JEITA位保留 |

每个需要改变的字段写后读回；已相同字段由本次读取确认、不重复写。最终再次读取检查全部值。任何失败都停止后续配置并尝试清除CHG_CONFIG；清除失败输出DISABLE NOT CONFIRMED，不声称硬件已禁充。不自动循环重试，不自动启充。

## 用户下一步

1. 保持电池断开，仅接5 V，重新编译/下载对应Keil_6/YP001_GR5526.uvprojx，目标YP001_GR5526_AC6。
2. 查看开机打印：`DISABLED PROFILE VERIFIED`；若打印PREPARE FAILED，不得接电池。
3. COM26，115200/8N1、CR结尾，执行`charger status`；必要时用`charger prepare`显式重试配置。probe/status不会重新配置寄存器，但读取REG09可能清除历史故障锁存。
4. 预期CHG_EN=0、OTG=0、WD=0、EN_TIMER=1、EN_TERM=1、IIN=500mA、ICHG=100mA、VREG=4200mV、IPRE/ITERM=20mA。
5. 等超过40秒再次读取，确认不恢复默认2040mA；复位后再次检查。保留FAULT_HISTORY/FAULT_NOW原始结果，不用历史故障标志冒充当前故障。
6. 本版读回通过后仍不接电池。先处理NTC门限、上电硬件禁充策略和正式充电参数，再安排带电池验收。
