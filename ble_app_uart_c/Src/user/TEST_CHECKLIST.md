# ETA69631 充电IC测试检查清单

## GPIO28特别说明
根据您的信息，GPIO28是普通GPIO，操作应该和GPIO18一样。这意味着：
- GPIO28使用 `APP_IO_PIN_28`
- 配置为GPIOB类型（`APP_IO_TYPE_GPIOB`）
- 使用标准GPIO MUX（`APP_IO_MUX_0`）
- 与GPIO18操作方式相同

## 硬件连接确认
✅ **GPIO28** → CHG_SDA (I2C数据线) - 普通GPIO，类似GPIO18  
✅ **AON_GPIO4** → CHG_SCL (I2C时钟线)  
✅ **AON_GPIO5** → CHG_INT (中断线)  

## 软件配置确认
- [ ] I2C地址: 0x6A (7位地址)
- [ ] I2C速度: 400kHz
- [ ] 中断模式: 双边沿触发
- [ ] 默认充电电流: 1000mA
- [ ] 默认充电电压: 4200mV (4.2V)
- [ ] 默认输入电流限制: 2000mA

## 常见问题排查

### 1. 编译错误
- **未定义的函数**: 检查是否包含了所有头文件
- **未定义的符号**: 检查所有源文件是否添加到工程
- **类型不匹配**: 检查函数声明和定义是否一致

### 2. 初始化失败
- **I2C通信失败**: 检查I2C引脚连接
- **设备未检测到**: 检查I2C地址是否正确
- **电源问题**: 检查充电IC电源是否正常

### 3. 状态不更新
- **中断配置错误**: 检查中断引脚配置
- **I2C通信超时**: 检查I2C速度是否合适
- **寄存器访问失败**: 检查寄存器地址是否正确

### 4. 电池信息异常
- **电压值异常**: 检查电压转换公式
- **电流值异常**: 检查电流转换公式
- **数据格式错误**: 检查寄存器读取顺序
