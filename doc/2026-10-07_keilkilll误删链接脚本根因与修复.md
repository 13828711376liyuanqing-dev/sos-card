# keilkilll.bat 误删链接脚本：根因与修复

修改人：SAM。修改时间：2026-10-07 11:50 +08:00（北京时间）。

## 根因

原 `keilkilll.bat` 包含 `del *.sct /s`，以运行时当前目录为起点递归删除链接脚本。`.sct` 是本工程的链接输入，Keil 不会在重新编译时自动生成，因此每次执行旧 BAT 都会再次造成 `L6031U` 和 AXF 无法生成。

原脚本还递归删除 AXF、备份、HTM 等文件，范围超过本项目中间文件。之前只恢复 `.sct`、添加 Git 忽略例外，没有修掉这个删除入口；`.gitignore` 不约束 BAT 的删除操作。

## 使用

在本项目根目录双击 `keilkilll.bat` 即可清理，随后正常在 Keil 编译。

命令行预览：`keilkilll.bat -NoPause -Preview`。

命令行清理：`keilkilll.bat -NoPause`。

BAT 与 `tools/Invoke-KeilClean.ps1` 配套，针对当前双工程目录结构使用；不得单独复制 BAT 当作通用递归清理脚本。
