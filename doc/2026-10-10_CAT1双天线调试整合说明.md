## 连接和操作

1. 更新两端程序后，PC USB 转串口连接汇顶 UART0：TX GPIO28、RX GPIO29、共地，115200 8N1。CAT1 通道沿用 AON_GPIO2/3 UART4 MUX0，接模块 UART1；新应用仍为 460800 8N1。
2. 汇顶启动仅打开CAT1电源，先完成USB底包与Lua烧写；不上报自动READY，不自动发AT。
3. 打开上位机选择COM26连接（连接不发送命令），手动点“桥接460800”并查询状态，确认模块STATUS ACK后再采样。详见 `2026-10-10_CAT1先供电后USB烧写说明.md`。
4. 填写天线编号，选择 ALL（4G＋GNSS）、间隔默认 2 秒，点“开始采样”。必须收到模块 START ACK 才显示采集中。初次启动未就绪可超时，待模块就绪后“查询状态”重新同步，再启动。
5. 点“停止”，收到 STOP ACK 才是停止确认；关闭软件/拔串口不会保证模块停止。停止天线采样只释放本次 GNSS 标签，不关闭其它业务的定位需求，也不关闭 LTE 入网。
6. 点击日志目录文字打开保存位置。每次连接新建独立会话目录，`raw.log` 记录带时间戳的收发，`samples.csv` 持续保存天线编号、采样字段和原始帧。文件写失败会显示错误，不静默继续。

等效手动串口命令（每行 CRLF）：

```text
cat_baud 460800
cat1_power on
cat_at AT+ANTSTATUS
cat_at AT+ANTSTART=ALL,2
cat_at AT+ANTSTOP
```

`cat_at` 也可下发原应用 HELP、AT_INFO、GNSSINIT、GNSSINFO、GPSTEST 等已注册命令。它转发模块命令，不实现全部业务状态机；原 `at` 命令仍依赖未启动的 Cat1Svr AO，本轮使用 `cat_at`。原 `cat_diag` 白名单保留，若换回标准 AT 底包，先执行 `cat_baud 115200`。

## 指标解释与来源

4G：CSQ、注册状态、RSRP、RSRQ、SNR、RSSI、Cell/TAC。注册 1/5 分别表示本地/漫游；单纯有 SIM 或 CSQ 不能证明注册成功。

GNSS：定位标志、可见/使用卫星数、HDOP、十进制度纬度/经度、本轮首次定位耗时和运行时间。`exgnss.rmc(2)` 用于十进制度；无有效定位时坐标为 NA。首次定位耗时不是清星历后的冷启动 TTFF，定位已存在时可接近 0。

NA 表示未知、不支持或返回值存在歧义。CSQ=99 显示未知；mobile API 的失败返回 0 与某些真实极弱值重叠，所以 CSQ=0/SNR=0 保守显示 NA。CN0 单位尚未确认，固定为 NA；`snr_max` 保存 GSV 原始 SNR 最大值，界面明确“单位待核”，不把它标为 dB-Hz。不能用这些链路指标替代天线阻抗/驻波/效率测试。

本轮核对的官方 API 源码 URL、行号和 SHA256 见 `logs/cat1_antenna_20261010/lua-report.md`。读取官方最新源码只是调用依据，目标 V2052 固件实际 API 仍需模块验证。
