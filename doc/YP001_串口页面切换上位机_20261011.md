# YP001 串口页面切换上位机（2026-10-11）

## 修改内容

新增 `tools/epd_page_serial.ps1`。上位机通过汇顶 UART0 发送既有 CLI 命令 `epd_page <page>`，提供 COM 口、6 个页面按钮和日志窗口。使用 Windows 自带 `System.IO.Ports.SerialPort`，不依赖 Python/pyserial；默认参数为 115200、8N1，命令以 CR 结束；不修改固件、显示驱动、CAT1、充电或下载配置。原 Python 版本仍保留供命令行使用。

## 使用

双击 `tools/启动页面切换上位机.bat` 即可启动，无需安装 Python。选择实际汇顶 UART0 串口后点击“打开串口”，再点击页面按钮。

选择实际汇顶 UART0 串口后点击“打开串口”，再点击页面按钮。若电脑端不是 COM26，使用设备管理器显示的端口；不要把 CAT1 USB 的 COM21/22/23 当作汇顶 UART0。
