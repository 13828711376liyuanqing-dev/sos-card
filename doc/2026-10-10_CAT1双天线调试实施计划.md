## 约束与架构

- PC → GR5526 UART0（115200 8N1）→ UART4 → Air780EGH UART1（460800 8N1）。新桥接命令 `cat_at <文本>` 按空格重组，最多 480 字节（含 CRLF），保持原有 `at`、`cat_diag` 兼容路径。运行时 `cat_baud 115200|460800`，默认保留已验证的 115200；上位机连接后明确设置 460800。
- RX 按完整行输出 `[CAT1 RX] <模块原文>`，避免按块插入前缀破坏 JSON/指标。限制缓存、报告溢出/驱动异常；UART4 只允许一个驱动所有者。
- 不改变 LCD、充电、GPIO、Flash、Keil 配置；主工程和交付副本仅同步本轮目标文件，先验证相同并备份。
- SAM 注释包含北京时间、内容和原因。主机验证与设备实测分开。
- 上位机为 C# WinForms / .NET Framework 4.x，使用本机 csc 编译；本地串口与本地日志，不依赖网络或 Python。日志文件写失败必须可见。

## 串口协议 v1（所有组件共用）

模块命令：`AT+ANTSTART=ALL,2`（或 `LTE` / `GNSS`，间隔 1–60 秒），`AT+ANTSTOP`，`AT+ANTSTATUS`。

模块输出 ASCII 单行，CRLF 终止：`[ANT] v=1 type=ACK op=START ok=1 mode=ALL interval=2`。失败 `ok=0 error=<无空格代码>`。STOP/STATUS 同理，STATUS 包含 running=0|1。`seq` 在每个采样帧递增。

- LTE：`[ANT] v=1 type=LTE seq=1 csq=20 reg=1 rsrp=-90 rsrq=-10 snr=12 rssi=-65 cell=123 tac=456`
- GNSS：`[ANT] v=1 type=GNSS seq=2 fix=0 sats_view=NA sats_used=NA cn0_max=NA lat=NA lon=NA hdop=NA elapsed_ms=2000 ttff_ms=NA`
- 未知/不支持字段为 `NA`。CSQ=99 为未知，禁止替换成有效信号。定位无效时坐标为 NA；TTFF 是本轮启动至第一次有效定位的时间，并非清除星历后的冷启动 TTFF。卫星指标必须依据真实 API 定义；不可用则保留 NA。
- ACK=START 是模块接受命令；汇顶 TX 成功仅表示串口发送成功。上位机必须等待 ACK 并设超时，不得发送后立即显示测试成功。STOP 超时保留“停止未确认”。断口/重连不复用旧采样状态。采样长时间未更新标记过期。
