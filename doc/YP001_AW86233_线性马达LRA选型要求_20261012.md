# YP001 保留 AW86233 时的线性马达（LRA）选型要求

日期：2026-10-12。用途：把原已装好的 AW86233 双端驱动电路改配真正的 LRA，不把现有 3.3V 偏心旋转马达（ERM）误当成 LRA。

## 结论

现有 U8 的 HDP/HDN 经 FB3/FB4 到 MOT+/MOT-，适合连接**两线交流驱动的 LRA**。原厂 `AW8623X_Hardware_Design_Guide_CN_V1.0` 第9页给 AW86233 的 ERM/LRA **最小负载阻抗6Ω**；这是允许下限，不是推荐值。原厂 `DS_AW8623X_EN_V1.4` 第11页在8Ω+100µH与16Ω+100µH负载上给出输出电压示例，并给3Ω过流检测阈值。不能仅靠直流电阻确定振感。

## 采购/打样时向马达厂索取的参数

| 参数 | 此板的选型原则 | 理由 |
|---|---|---|
| 类型 | 明确标为 LRA / 线性谐振执行器，两线差分交流驱动 | ERM 即使电阻相同，也不能用 CONT 共振驱动来验收 |
| 线圈直流电阻 `RL` | **不低于6Ω**；首轮打样可优先比较约 **8–20Ω** 的样品（工程建议，不是芯片硬性上限） | 8/16Ω有原厂表征示例；阻值越低越要核算 Q1、VCC_SYS、U8 和走线峰值电流。32Ω LRA不被此下限排除，但相同电压下电流较小，振感须实测 |
| 共振频率 `F0` | 若想先沿用当前约170Hz测试参数，选标称 **170Hz附近**并取得容差/温漂；量产固件应检测实际 F0 并跟踪，不把170Hz当固定硬件要求 | 当前 `0x18=0x8D`，按原厂 `F_PRE=24k/code` 得约170.2Hz；当前测试 `TRACK_EN=0`，失谐会显著降低振感 |
| 额定驱动电压 | 要求厂家写明**在 F0 下的额定交流电压及其单位（Vrms、Vpeak或Vpp）**、最大短时过驱值与允许时长；不要只写“3.3V” | LRA 工作电压是两端差分交流量，不能与 ERM 的3.3V直流额定值混同 |
| 电感/BEMF/响应 | 索取线圈电感、F0测试条件、反电动势和加速度/振感曲线、额定/最大持续时间、安装方式 | 关系到 AW86233 的 F0检测/跟踪、刹车效果及整机实际振感 |

AW86233 芯片 VDD 工作范围约 **2.7–5.5V**，当前板上 VDD_MOT 曾测约4.17V，属于芯片允许范围；**不意味着 LRA 会承受恒定4.17V**。输出由波形、驱动电平和负载决定。原厂在 VDD=4.2V、8Ω+100µH 与16Ω+100µH 测试条件下的输出峰值示例分别约3.6V、3.8V；这不是所有马达/所有模式的保证值。应选额定/最大差分电压落在可控范围内的 LRA，并以示波器 `MOT+−MOT-` 实测 Vrms/峰值、温升及振感来定最终配置。

给供应商的**第一轮询样目标**可以写为“两线 LRA、约16Ω直流电阻、F0约170Hz、额定约2.0Vrms（在F0下，差分交流）、提供最大短时过驱值/时长及加速度曲线”。这是为了与当前板和诊断频率匹配的起点，不是 AW86233 的唯一可用规格，更不能跳过实板驱动电压和振感验证。

## 现有硬件与软件需要核对的点

- 使用 LRA 的 CONT/RAM/I²C 模式时，U8 pin7 PWM/TRIG1 **不必为了基础 LRA 驱动而补接 GR5526 PWM**；现有 I²C3、GPIO26电源、GPIO27复位、MOT+/MOT- 即可进行基础调试。马达应固定到实际外壳/结构件上验收，悬空手持的体感不可替代装机测试。
- 当前 `motor_test` 是一次约120ms的低幅度诊断脉冲：`DRV1_LVL=0x20`、`DRV2_LVL=0x10`，约对应 VDD 的25%/12.5%无载设定；它仅证明通讯与芯片进入 CONT，不是新 LRA 的量产驱动参数。
- 选定 LRA 后，固件应先读 CHIPID、故障，再按马达标称 F0设置 `F_PRE`，使用原厂 F0检测/跟踪流程（需要根据该马达 BEMF 能力调校），再设额定驱动电平、过驱时间及刹车；测失败时停机。当前 `TRACK_EN=0`、F0固定、驱动偏弱，需要重新标定。
- 按所选 RL 和目标电压核对 VCC_SYS/Q1/R45/U8 的电流、去耦和电压跌落。原厂建议 VDD/VREG 与 HDP/HDN走线短粗，输出远离充电IC噪声源以保证 F0 检测。若低阻 LRA 在启动时使 VDD_MOT下跌，不能只改寄存器掩盖供电问题。

## 实板验收

新 LRA 上板后分别记录：断电线圈电阻；COM26芯片ID和故障位；F0检测值与供应商标称值；`MOT+−MOT-` 实际差分频率、Vrms和峰值；VDD_MOT启动跌落及电流；外壳固定状态的振感/噪声/温升与停止刹车。通过其中任一单项都不等于整机振动功能通过。
