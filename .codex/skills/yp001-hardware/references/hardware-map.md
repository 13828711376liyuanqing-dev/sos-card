# Hardware map — YP001 A1

Consult the original schematic for polarity and power domain before altering firmware. This map is from schematic A1 2026-09-09 and the QFN68 MUX spreadsheet; installed parts and values still require BOM/board confirmation.

## Rails and display (schematic pages 1 and 3)

`VCC_SYS → U1005 IN (pin 4, SGM2031-3.3V) → U1005 OUT (pin 1) → EPD_VDD`.
`GR5526 GPIO10 (QFN pin 14) → LCD_VCI_EN → R84 (1 kΩ) → U1005 EN (pin 3)`; R83 (100 kΩ) pulls EN toward ground. U1005 GND is pin 2. C35 (1 µF) is input bypass, C90 (1 µF) is output bypass. U1005 NC is pin 5. Confirm which side of R84 was measured; a high GPIO latch does not prove EN high.

Display FPC nets: EPD_VDD; EPD_LCD_BUSY via R96 0Ω to GR5526 GPIO24/QFN55; EPD_LCD_RST via R97 0Ω to GPIO25/QFN56; EPD_LCD_RS/D-C via R99 0Ω to GPIO32/QFN63; EPD_LCD_CS via R100 0Ω to GPIO33/QFN64; EPD_LCD_CLK via R101 0Ω to GPIO31/QFN62; EPD_LCD_DATA via R102 0Ω to GPIO30/QFN61. Check original drawing for each reference position before probing. Panel also has GDR, RESE, PREVGH/PREVGL, generated by its drive circuit. Page title says AMOLED, while interface/boost components resemble EPD; user confirmed DEPG0150 panel on current board.

With **EPD_VDD = 1.2 V** measured on 2026-09-30, measure U1005 IN, EN, OUT relative to U1005 GND. Expected OUT for enabled, correctly supplied, unloaded SGM2031-3.3V is around 3.3V, subject to manual limits. Distinguish low IN, low EN, regulator failure, and overloaded/shorted OUT. Do not infer which branch is true from the output alone.

## Audio (schematic page 2)

Air780 controls ES8311 over its I2C and supplies the I2S clock/data path. ES8311 differential output feeds U5 HAA9209 speaker amplifier. Air side signals control audio/PA supply and enable. U901 is an additional K-QFN-20 block in the drawing; obtain BOM before identifying it as a populated specific amplifier. Do not reassign ES8311 I2S to GR5526 based only on chip capability.
