# YP001 GR5526 整板硬件分析与改善建议

更新：2026-09-30。此MD替代此前错误结论；同名旧PDF尚未更新。完整代码修复记录见 `YP001_软硬件与框架总体复核_20260930.md`，引脚见 `YP001_GR5526管脚配置清单.md`。

## 主要IC功能和搭配

| IC/模块 | 作用 | 搭配判断 |
|---|---|---|
| GR5526RGNIP/QFN68 | BLE主控、按键、传感器和板级控制 | 已对照原图与复用表修正工程；电源/RF/晶振布局仍需PCB资料 |
| Air780EGH/同系列CAT1 | 蜂窝连接及模块固件业务 | GR5526经AON2/3的UART4通信；实际模块型号与固件命令集需确认 |
| ES8311 | 单声道音频编解码 | 原图I2S/I2C由Air780侧连接，GR5526不应直接争用总线 |
| U5 HAA9209 | 扬声器功放 | 接ES8311 OUT_P/N，核对Air侧音频电源/PA控制 |
| AW86233 | 振动马达驱动 | GPIO11/12 I2C3；GPIO26/27供电与复位；AON6中断 |
| ETA69631 | 电池充电/电源管理 | GPIO4/5 I2C4，AON5中断，GPIO20/21 NQON/STAT |
| U1104 三轴 | 运动检测 | GPIO2/3 I2C0，GPIO7供电，AON7中断；原图未确定为DA221 |
| 显示模组 | 电子纸特征的显示接口 | EPD网名/升压电路与标题AMOLED有歧义，需精确屏料号确认 |

原图另有U901功放图块，只见K-QFN-20标记，不能据封装认定料号或实际装配。请以BOM和实板为准。

## 确认的连接关系

1. G-sensor与马达分属I2C0/I2C3，并不存在此前所述共用冲突。充电使用第三条I2C4。
2. `gr55xx_hal_aon_gpio_ex.h`明确AON2/3 UART4 MUX0。普通GPIO HAL表不覆盖AON域。
3. CAT1电源由GPIO6经Q1201/Q2控制，MCU高有效；VBUS/Q10可能独立保持电源。
4. PWRKEY_EN经Q4 NPN反相，MCU高使模块PWRKEY低；已更正默认释放电平和脉冲极性。
5. Air780侧I2S、控制I2C与ES8311相连，音频调试必须包含Air侧固件、时钟和供电时序。

## 改善建议（待实测决定硬件变更）

- **电源**：示波器观察CAT1发射和最大音量时电源跌落；核对走线阻抗、储能/去耦和电池峰值能力。USB与电池两种条件分别确认上电/关机，不把GPIO6低视为完全掉电。
- **接口电压**：传感器等图示1.8V上拉应与GR5526对应I/O电源域匹配；查实板上拉、电平转换和未供电反灌。未测量前不擅自改变上拉或IO电压。
- **音频**：检查ES8311 MCLK/BCLK/LRCK、数据方向/采样率、MIC偏置、模拟地/数字地回流；PA使能最后打开、关机先静音的时序须结合器件手册和POP波形确认。
- **充电**：根据电芯规格核对充电终止电压、电流、输入限流、温度保护及热设计。旧驱动寄存器不能直接作为ETA69631验证依据。
- **马达**：确认执行器类型、额定驱动和AW86233配置；先单模块限幅调试再接业务。不要仅添加I2C地址即认定可振动。
- **显示**：取得屏规格/FPC定义/控制器/LUT，检查升压、电源稳定时间、RESET、BUSY与SPI抓包，再验收全屏；原图标题不足以决定换屏或重写驱动。
- **调试可维护性**：保留SWD GPIO0/1、UART0 GPIO28/29及地/电源测点；生产引入唯一设备身份和可读版本号。
- **PCB**：后续需PCB/网表/BOM才能验证封装、焊盘、电源/RF/音频布局与装配。原理图匹配不能代替PCB兼容结论。

## 当前结论

确定性引脚/控制极性与框架问题已改代码；完整模块联通尚未验证。本轮仅做静态/原理图核对，没有编译、下载、充放电、音频、RF或屏幕实测。下一步按总体报告中的分模块顺序验收，不同时开启所有未验证模块。
