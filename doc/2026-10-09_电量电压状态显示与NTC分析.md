## 2. 屏幕行为

保留SOS CARD、BLE、ALARM，电池区增加电量条、`xx% EST`、电压和充电状态。无有效电压或NTC异常时电量为`--`。新数据最多每10秒触发一次刷新，数值和状态未改变则不刷新。

| 屏幕文字 | 含义 |
|---|---|
| CHARGING | 芯片报告预充/充电，且CHG_EN有效 |
| EXT IDLE | 有外部输入，当前未报告正在充电 |
| CHG DONE | 芯片报告充电终止；受控测试随后停充可能转为EXT IDLE |
| BAT SUPPLY | 无输入、有效电池端电压且NTC正常；未测量电流方向 |
| NO INPUT | 无输入且电池状态不足以确认 |
| NTC FAULT / CHG FAULT | 芯片当前NTC/其他故障 |
| I2C ERROR | 无有效芯片状态或停充尚未确认；查看串口进一步判断 |
| ADC RANGE | ADC接近饱和/校准电压超过量程，电压和电量显示未知 |

启动页在第一次周期采样前显示未知。屏幕刷新失败会打印`[BAT UI] refresh failed; screen may be stale`；电子纸保留旧像素，仍需以串口当前读回判断状态。

### 电压采样

GPIO23拉高使Q8/Q9导通，等待50ms分压节点建立；MSIO_A1采用单端CH_N、1.6V内部参考、16kHz ADC时钟。采36点，丢弃前4点，使用SDK/eFuse校准换算32点，再去掉一个最大和最小值取平均。每次结束关闭采样开关并释放ADC。

GR5526数据手册Rev1.3第590～592页明确：13位单端范围为0～2×Vref，并建议丢弃启动的前2～3点；源阻抗较高时应降低采样率。1.6V参考要求芯片供电至少3.2V，需实测确认现板满足此条件。

`Vbat = Vadc × (100+316)/316 = Vadc × 1.316455696`

| 电池端电压 | ADC端理论值 | 1.6V参考时 |
|---|---:|---|
| 3.00V | 2.279V | 量程内 |
| 3.90V | 2.9625V | 量程内 |
| 4.20V | 3.1904V | 接近3.2V上限，余量约9.6mV |
| 4.35V | 3.3043V | 超量程 |

实际电阻公差、参考误差可能使4.20V附近提前出现ADC RANGE。当前硬件不覆盖4.35V全量程。不能通过改变乘数恢复饱和后的信息；正式4.35V方案需重新确认分压设计。软件未擅自修改硬件，也未选用供电条件不满足的2.0V参考。

串口每10秒可见`[BAT] raw=... ADC=...mV BAT=...mV EST=...% R42=100k R13=316k`。失败输出错误分类。SDK的同步ADC接口虽然接收timeout参数，但源码未把它传给HAL；本版不把该参数当成独立硬件停充保证。

### 电量估算的定义

缺少这块临时电池的实测SOC/OCV曲线，当前采用明确标注的线性电压估算：

`EST = clamp((Vbat_mV - 3000) × 100 / 1350, 0, 100)`，整数向下取整。

3.0V→0%，3.9V→66%，4.2V→88%，4.35V→100%（最后一点仅是算法端点，当前ADC硬件无法完整测到）。这不是剩余mAh或标准容量百分比，充电/负载造成的端电压变化也会影响显示；不用它控制充电、关机或容量验收。正式电池应依据静置/带载曲线重新标定。

## 3. NTC 与 R62/R63 的关系

20260911原理图第1页：R61从LDO上拉TS；R62从TS到GND；R63标为NC/NTC，也是TS到GND的可选热敏支路；电池接口NTC连接同一TS节点。**R63不是串联调节电阻。当前R62/R63都不贴，仅电池NTC参与下拉。**

`Rntc(T) = 10000 × exp[3435 × (1/(T+273.15) - 1/298.15)]`

`Rdown = Rntc || R62 || R63`（未贴视为开路），`TS/LDO = Rdown/(R61+Rdown)`。

如果R63另贴板上NTC，电池NTC和板上NTC可能处在不同温度，此时不能把它们当成一个准确的电池温度传感器。本次紫色对比曲线仅假设两只NTC同参数、同温。

![NTC曲线](D:/CODEX/sos-card/doc/2026-10-09_NTC_R62_R63曲线.png)

| 理论配置（R61均为10k） | 25℃ TS/LDO | 冷停73.3% | 偏冷68.3% | 偏热44.8% | 热停34.4% |
|---|---:|---:|---:|---:|---:|
| **当前：R62/R63不贴，电池NTC** | **50.0%** | **约0.97℃** | **约6.38℃** | **约30.50℃** | **约42.70℃** |
| 旧配置：R62=10k、电池NTC | 33.3% | 无交点 | 无交点 | 约-8.54℃ | 约22.49℃ |
| 对比：R62不贴、R63再贴同温10k/B3435 NTC | 33.3% | 约-13.40℃ | 约-8.55℃ | 约12.97℃ | 约23.77℃ |

旧R62=10k与电池NTC并联时，25℃等效下拉5k，TS/LDO=1/3，低于34.4%的热停典型值，能解释室温不充电。R62固定10k时，即使NTC趋于无穷大，TS/LDO也不超过50%，因此不能达到73.3%冷停阈值。

当前R62/R63不贴时，25℃在正常区。表中所有温度均为典型参数理论交点，未包含电阻/NTC/B值误差、阈值公差和迟滞，不能当温箱验收结果。软件受控测试拒绝warm/cool等所有非正常NTC状态，因此本版理论放行窗口约6.4～30.5℃，仍按有人看护室温测试执行。

## 6. 下一步实板验证

1. 用本轮新工程编译/下载后，确认约10秒内出现`[BAT]`日志及屏幕状态。保留R62/R63不贴。
2. 初次先保持禁充，按既定受控测试接线条件接入电池，对照万用表电池端电压。采样开关仅短时导通，TP1/ADC_BAT用示波器观察该采样窗口，不能用窗口外的0V判为分压故障。
3. 例如电池3.90V，ADC端应约2.9625V；串口BAT和万用表比较，误差明显先检查实装/参考供电/采样建立，再决定校准。不要凭屏幕数字验收。
4. 检查有5V禁充时EXT IDLE；NTC故障时NTC FAULT；批准的手动start后CHARGING，以及stop/60秒到时后状态变化。屏幕有最多10秒调度延迟并受刷新时间影响，以当前串口为准。
5. 正式电池仍需解决4.35V量程覆盖、实测SOC曲线、温度公差/迟滞和失联停充验证。当前受控测试不作容量验收。
