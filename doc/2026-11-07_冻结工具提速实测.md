SAM | 2026-11-07 09:45 +08:00 | 本轮只修改主机冻结工具，不编译、烧录或调整硬件。

## 本轮结果

`tools/version_control/baseline.py` 保持 `YP001_LOCAL_BASELINE_V1` 清单及 `freeze(root, spec, output)`、`verify(directory, expected_manifest_sha256)` 接口。

在 254 个**逐文件显式映射**输入、共 4,491,264 字节的合成样本上，交替执行旧、新、新、旧四轮：旧工具均值 16.679 秒，新工具均值 6.848 秒，约 **2.44 倍**。四轮 `files` 清单的路径、来源、大小及 SHA256 逐项相同。完整 manifest 的生成时间不同，因此完整 manifest SHA256 不相同，这不是字节清单不一致。

先前单目录输入试验也保留在 `logs/version_control_20261107/benchmark/synthetic_5053691c4bd740f6b8a411e78d96a0e3/benchmark.json`，不是代表真实逐文件 spec 的主结果。

## 修改及原因

| 文件/函数 | 修改前 | 修改后及原因 |
|---|---|---|
| `baseline.py:safe_path/collect` | 逐文件、逐轮反复检查全部祖先；目录扫描后还逐文件检查祖先 | 同一次扫描缓存已检查组件，显式文件输入也复用；后续扫描重新建立缓存，不跨扫描相信旧状态 |
| `baseline.py:scan` | `os.walk` 后另行多次查询链接/文件属性 | `os.scandir` 使用不跟随链接的缓存 stat；检查全部条目的 symlink/reparse，包括将被排除的 Objects 目录 |
| `baseline.py:copy_one` | 源 SHA、copy2、目的 SHA、源 SHA、最终源 SHA、最终目的 SHA，多次串行读 | 固定 4 个工作线程；源文件一次流式读取时同时计算 SHA256 和写入独占新文件；保留最终源 SHA 与目的 SHA 复核 |
| `baseline.py:freeze` | 依次复制，目标文件/目录冲突到写入时才暴露 | 提前拒绝目标前缀冲突；输出不覆盖，单文件 `xb` 独占创建；失败保留不完整输出，不写成功清单 |
| `baseline.py:verify` | 核验文件后缺少第二次文件集检查 | 每文件 SHA 前后检查身份/大小/mtime；全部 SHA 后重新扫描精确文件集、大小与 reparse，拒绝校验期间新增项 |
| `test_baseline.py` | 8 项基础回归 | 17 项合成回归，覆盖恢复 mtime 的同尺寸内容漂移、读流中改动、新增文件、真实 junction、校验期间新增文件/链接、外部清单锚点与不覆盖 |
| `benchmark_freeze.py` | 无可复现前后基准 | 固定合成样本、交替顺序、新输出名、逐项库存比较、JSON 耗时证据 |

旧实现备份为 `logs/version_control_20261107/perf_before.py`，只用于基准，不替换活动入口。不得用可变工作树的硬链接充当冻结副本。本轮没有实现跨版本内容对象去重或增量备份。

## 验证命令与边界

```powershell
python -m unittest discover -s tools/version_control -p test_baseline.py -v
python tools/version_control/benchmark_freeze.py --old-engine logs/version_control_20261107/perf_before.py --evidence-root logs/version_control_20261107/benchmark
```

17 项测试通过，最后一轮测试耗时 3.538 秒。第一次加入文件句柄身份检查时出现 Windows Python 3.12 `lstat/fstat` 的 `ctime_ns` 语义差异；实测确认后改用设备号、inode、大小、mtime 比较，保留最后的内容 SHA256，未以时间戳替代内容核验。

这是普通文件系统上的尽力一致副本，不是 VSS 原子快照。工具检测到了测试中“同尺寸改写并恢复 mtime”的持续变化，但无法承诺捕获检查窗口之间发生并完全撤销的变化，或阻止有意竞争的文件系统替换。正式冻结期间仍应停止源码编辑、生成和外部同步。4 线程在不同硬盘、杀毒软件、缓存及并发负载下的收益会变化。
