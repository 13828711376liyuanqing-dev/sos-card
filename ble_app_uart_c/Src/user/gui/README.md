# 200×200 电子纸主界面

来源对照：`D:\SVN\GR5526_SDK_V1.0.4\YP01_lvgl_831` 的首页卡片与状态信息层级。当前项目保留自身的 QP、DEPG0150 驱动和业务流程；已接入 LVGL 8.3.1，只实现与当前设备相关的 BLE、告警、电池三行状态，不引入 FreeRTOS、触摸驱动、454×454 图片或外部资源 Flash 布局。

- `epaper_home.h/.c`：纯 200×200、1 bit 画面生成。输出按现有 DEPG0150 驱动的 `frame[x * 25 + y / 8]` 顺序存放。白底为 `0xFF`，黑点清零。
- `epaper_lvgl.h/.c`：当前主界面的 LVGL 绘制和 1-bit 电子纸帧缓冲适配。
- `../../external/lvgl_8.3.1/src/draw/sw/lv_draw_sw_letter.c`：字形位图按整字节对齐的行跨度读取，避免 B、E、M 等字符出现斜线错位。
- `../epaper_depg0150.c`：开机通过 `epaper_depg0150_display_demo_image()` 显示 `Logo/YP_01.png` 对应的 1bpp 启动 LOGO，不再叠加临时“测试OK”；BLE 初始化后再显示主界面。
- `../epaper_depg0150_logo_yp01.c/.h`、`../../../Logo/YP_01.png`：启动图的 PNG 原图与 200×200、1bpp 列优先编译资源。数组布局为 `frame[x * 25 + y / 8]`，像素高位优先，1=白、0=黑。
- `../../platform/bsp.c`：BLE 初始化后显示主界面。BLE 显示本次初始化结果；告警和电池目前没有可在该启动点读取的统一有效数据，暂显示 `--`。

待审核差异：SVN 的彩色触摸手表页面不能原样运行在 DEPG0150。当前只移植适合 200×200 单色屏的状态信息层级。若要显示实时告警、电池百分比或其他页面，需要明确数据来源、刷新时机和电子纸刷新频率，再接入业务事件。

此前版本验证记录：Keil AC6 编译 0 错误、0 警告，J-Link 下载校验通过；从板上 RAM 读回的最终 5000 字节帧缓冲显示完整字形。该记录不代表本轮新 Logo 已编译、下载或通过实屏确认。
