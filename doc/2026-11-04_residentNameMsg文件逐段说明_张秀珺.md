SAM | 2026-11-04 | 读者：后台开发

## 时间戳是哪个字段

**`Seq`**。值 = 生成文件时的当前时间（Unix 秒）。

- 这个文件是 `1730600000` = 2024-11-03，**错了**，应是生成时的当前时间（例如 2026-11-04 15:00 ≈ `1793775600`）。
- 设备只收比上一次更大的 `Seq`，小了会被当成旧消息拒收。

## Glyphs：每一项是一个字的一个字号

| 字段 | 例（张 32px） | 含义 |
|---|---|---|
| `U` | `5F20` | 字的 Unicode 码点（十六进制），5F20 = 张 |
| `S` | `32` | 字号：32 主页姓名，16 低电页姓名和园区 |
| `W` / `H` | `28` / `28` | 点阵宽、高（像素） |
| `X` / `Y` | `2` / `-3` | 点阵左边距、底边相对基线的位置 |
| `A` | `512` | 前进宽度，= 字号 × 16 |
| `D` | base64 | 点阵数据，每行补齐到整字节 |
| `C` | `D44B` | CRC-16 校验码，设备收到后重算，不对就拒收 |
