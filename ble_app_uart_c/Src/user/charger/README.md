## 电路与软件边界

- U2 SCL/SDA → GR5526 GPIO4/5，I2C4 MUX0；nINT → AON_GPIO5；STAT → GPIO21（经 R60 1 kΩ）。
- nCE 经 R57 0Ω 接地，芯片具备自主充电条件；GPIO20 到 nQON 的 R11 标为 NC，不能把 GPIO20 拉低当作有效充电使能。
- TS 网络在图纸中含 `NC/NTC` 可选位。实际 NTC 装配、阻值、电池容量和 USB 供电能力尚未确认。板上装配状态要用实物/BOM 核对。
- ETA69631 没有现有 `eta69631.c` 所声明的电池/系统电压 ADC 寄存器。`REG00/02/04` 是限流/电压设定值，不能显示为实测电流或电压；电池电压要从板上的 `ADC_BAT` 独立采集和校准。

## 使用

- CLI `charger probe`：初始化 I2C4 并检查 `REG0B[6:0] == 0x3F`；不写芯片寄存器。
- CLI `charger status`：读 `REG08/09/0A` 状态及 `REG00/02/04` 设定值；不写寄存器。
- `yp001_charger_set_enabled(false)`、`yp001_charger_apply_profile()`、`yp001_charger_set_enabled(true)` 是显式写入接口。配置要求先禁用充电，写后逐项回读，且本版本将输入限流和快充电流限制在 500 mA、充电电压限制在 4.20 V。配置时关闭 REG05 的 I²C 看门狗以免参数恢复默认；REG05 的独立充电安全定时器保持原值。使能前再回读参数。它们没有接入启动流程或 CLI。

## 审核点

上电后 nCE 已接地，手册说明芯片默认 `CHG_CONFIG=1`、快充电流约 2040 mA、输入限流可能由源检测更新。软件暂不自动改写这些值。要启用受控参数流程，先确认电池规格、NTC 实装、USB 输入额定能力，以及上电瞬间是否允许芯片自主充电；仅改软件不能消除上电到 MCU 配置完成之间的自主充电窗口。

旧 `charge_ic.c` 和 `eta69631.c` 保留以免覆盖既有工作，但已从当前 Keil/GCC 源文件清单移除。它们的寄存器解释、参数写入和电压读数不能作为 ETA69631 验收证据；当前 QP 启动路径也没有调用它们。
