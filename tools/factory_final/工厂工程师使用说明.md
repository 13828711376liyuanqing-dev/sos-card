# YP001 装壳成品蓝牙测试工具 V1

本版供工厂工程师试测：外壳已装好，通过蓝牙连接，不需要拆壳测板内电压。请先在单台样机确认流程，再用于批量试测。本工具记录检查结果，不替代尚未冻结的正式生产放行标准。

## 准备

- 电脑：64位 Windows 10（2004或更新）/Windows 11，.NET Framework 4.8，支持BLE的蓝牙适配器及正确驱动，打开Windows蓝牙。普通仅经典蓝牙的适配器不适用。
- 当前Windows用户可写入LocalAppData目录。运行不需要Python、Keil或Windows SDK，不需要上位机联网。
- 产品须预先烧入配套`YP001_FT1_20261013.hex`。旧版YP001广播固件没有工厂GATT服务，连接时会明确报错。固件需按已有烧录流程在装壳前安装；此工具不承担烧录/OTA，不要求工厂拆已装壳成品。
- 准备机身IMEI标签、批次和工程师姓名。每次只操作一台，核对设备地址及机身标签；多台可能同名，不能只凭“YP001”名称选择。

## 普通检查

1. 插5V唤醒产品，待开机稳定，运行`YP001FactoryFinal.exe`。
2. 点击“扫描蓝牙”，等待12秒；在列表明确选择产品，再点击“连接”。不会自动选择或连接。
3. 填写工程师、批次、扫描/输入标签IMEI。“读取设备”显示设备IMEI、测试固件标识、内部ADC电压/估算电量、按键及业务状态。设备未知值保留未知；ADC不是外部测量。设备IMEI可能需要CAT1当前通信就绪，不把标签输入当设备实读。
4. 按表分别确认外观、屏幕/IMEI/二维码、左右键、运动、音频、4G、GNSS及船运恢复。实际测试用测试SIM/测试平台/测试号码，工具不会自动拨打SOS。
5. 每项选择“通过/失败/未测试”。不适用或未做的项目保持“未测试”，不要为了全绿选择通过。
6. 屏幕页测试：按住**左键**点击“按住左键解锁”，松开左键，再选择测试页并点击“显示测试页”。只按左键，不双键同按；正常SOS基线为双键3秒。解锁60秒有效，断连失效。页面受理不代表实屏清晰，请目视检查。
7. 点击“保存测试记录”，用“打开记录目录”查看`raw.log`和`report.csv`。

## 船运及恢复检查

1. 保持当前蓝牙连接，拔掉5V；确保没有报警/通话。按住左键解锁，再松开。
2. 点击“准备船运”：工具请求关闭CAT1供电，再等待原业务模块确认离线，随后检查无5V等条件。等待可达约25秒；失败保持记录，不强行确认。
3. 准备成功后，在界面有效期内点“确认进入船运”，再次核对当前地址/标签。设备接受后典型约12秒切断，蓝牙预计断开。
4. **蓝牙断开只说明通信消失，不能证明SYS=0V或零电流。** 装壳后人工观察按键/运动不使产品启动；电子纸保留图像不能判断是否仍通电。
5. 插5V恢复，重新扫描/连接并读取。工具按实读IMEI匹配关联原记录；IMEI未知时只允许工程师明确确认同标签进行人工关联，仍标未知。不同设备不能复用上一台结果。
6. 更新船运恢复人工结果并保存。最后正式包装时，再执行一次船运；之后不要插5V。包装提示“首次使用需接5V开机”。

“取消准备”仅在BATFET尚未尝试写入时有效；指令已接受/最终写入不确定时不能取消。失败或超时显示结果不确定，先重新连接读取，保留记录，不盲目重复操作。回执等待和通知发送都有超时保护。

## 记录与边界

记录位置：`%LOCALAPPDATA%\YP001FactoryFinal\sessions\<时间_唯一编号>`。界面显示实际目录；原始收发自动落盘，测试表须点保存，船运确认前后自动保存。记录错误会在界面显示，不静默判成功。CSV可用Excel打开。

本版不改写IMEI、居民姓名、呼叫号码或现有用户参数。持久化参数设置需另行补接口并验证重启保持。本版不测板内电压/充电电流/船运总电流；这些应由装壳前工序或专项样机验证。正式出货电量范围、功能阈值和抽检规则仍需冻结。本机测试不等于另一台工厂电脑兼容性已通过。
