# YP001 GR5526RGNIP/QFN68 管脚配置清单

更新：2026-09-30。依据YP001原理图、QFN68 Pin MUX表、SDK普通GPIO与AON GPIO HAL复用表。代码入口：`Src/user/yp001_board_config.h`。这是一份静态配置清单，不是实机验收记录。

## 分组与映射

GPIOA覆盖GPIO0～15，GPIOB覆盖GPIO16～31，GPIOC覆盖GPIO32以上；例如GPIO28在APP_IO_TYPE_GPIOB中使用APP_IO_PIN_12。AON和MSIO是独立端口，不能按普通GPIO编号查复用。

| 功能 | GR5526信号 | QFN68脚号 | 外设/复用与行为 |
|---|---|---|---|
| SWD | GPIO0/1 | 4/5 | 保留调试，不作CLI |
| G-sensor SCL/SDA | GPIO2/3 | 6/7 | I2C0 MUX0；已修正原I2C3误配 |
| 充电SCL/SDA | GPIO4/5 | 8/9 | I2C4 MUX0 |
| CAT1电源请求 | GPIO6 | 10 | GPIO MUX7，高有效；VBUS可能独立供电 |
| 传感器电源 | GPIO7 | 11 | GPIO MUX7，Pwr_Jkb第一参数控制 |
| 屏电源 | GPIO10 | 14 | GPIO MUX7，默认关闭 |
| 马达SCL/SDA | GPIO11/12 | 16/17 | I2C3 MUX2，独立于传感器总线 |
| 充电NQON | GPIO20 | 51 | GPIOB PIN4，低有效，默认释放 |
| 充电STAT | GPIO21 | 52 | GPIOB PIN5，输入；状态判读待驱动核对 |
| 电池分压开关 | GPIO23 | 54 | GPIOB PIN7，高有效开关网络 |
| 屏BUSY | GPIO24 | 55 | GPIOB PIN8，输入，极性随屏确认 |
| 屏RESET | GPIO25 | 56 | GPIOB PIN9，驱动时序随屏确认 |
| 马达电源 | GPIO26 | 57 | GPIOB PIN10，完整驱动未启用 |
| 马达RESET | GPIO27 | 58 | GPIOB PIN11，完整驱动未启用 |
| 调试TX/RX | GPIO28/29 | 59/60 | UART0 MUX2，115200 8N1 |
| 屏DATA/CLK | GPIO30/31 | 61/62 | GPIOB PIN14/15；当前屏驱动按GPIO接口处理 |
| 屏D-C/CS | GPIO32/33 | 63/64 | GPIOC PIN0/1 |
| CAT1 PWRKEY_EN | AON_GPIO0 | 38 | MUX7，默认低，MCU高经Q4使模块PWRKEY低 |
| KEY1 | AON_GPIO1 | 39 | MUX7，上拉/下降沿，APP_KEY消抖 |
| CAT1 TX/RX | AON_GPIO2/3 | 40/41 | UART4 MUX0，115200 8N1；业务AO未启动 |
| KEY2 | AON_GPIO4 | 42 | MUX7，上拉/下降沿，APP_KEY消抖 |
| 充电INT | AON_GPIO5 | 43 | 输入，驱动中断策略待核对 |
| 马达INT | AON_GPIO6 | 44 | 输入，完整驱动未启用 |
| 传感器INT | AON_GPIO7 | 45 | 当前代码双沿；有效极性需传感器规格确认 |
| LED红/绿/蓝 | MSIO_A3/A0/A2 | 34/37/35 | 对应板级宏，启动执行关闭 |
| 电池ADC | MSIO_A1 | 36 | 模拟输入，需校准参考电压/分压比 |

本表覆盖应用用到的信号，未把电源、地、晶振、RF与芯片专用脚当作GPIO配置；未用脚和电源域应继续按GR5526硬件设计指南与PCB核对。

## 启动默认与软件限制

- 主工程：`D:/CODEX/sos-card/ble_app_uart_c/Keil_6/YP001_GR5526.uvprojx`，目标 `YP001_GR5526_AC6`。
- QP启动路径中传感器供电开、屏供电关、CAT1电源请求关、PWRKEY释放；实际CAT1供电还受VBUS影响。
- 调试使用本板UART0 GPIO28/29，不能套用开发板J5 UART3 GPIO4/5配置，否则与充电I2C冲突。
- 两个按键只由APP_KEY注册。短按CAT1事件在CAT1 AO未启动时忽略；长按保留LocaSvr事件路径。
- CAT1引脚支持已确认，但当前 `at` 命令返回未初始化并不代表引脚错误；详见总体报告中的缓存生命周期问题。
- 马达、充电和屏幕的板级宏定义不等于完整驱动已经启用；软件行为应以有效调用路径为准。

## 验收

先编译，再核对电平/复用/波形/模块回应。电源、RESET、INT、BUSY有效极性必须按对应器件和实板确认，不以网名推断。完整后续步骤见 `YP001_软硬件与框架总体复核_20260930.md`。此前版本关于AON不支持UART4、传感器与马达共用I2C3的结论作废。
