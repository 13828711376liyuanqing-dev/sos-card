# YP001 AW86233 驱动 3.3 V ERM 马达：调试结论与硬件修改

日期：2026-10-12。当前状态：**电气通信和输出已验证；马达未产生可感知转动；硬件改线及 ERM 固件均尚未实施。**

## 已确认的实板结果

- 用户确认马达为偏心旋转马达（ERM），额定 3.3 V，本体直流电阻约 32 Ω；断电时 `MOT+`—`MOT-` 焊盘约 31.9 Ω，表笔短接约 0.3 Ω。此前 60 Ω 为误测，不能据此判断接线故障。
- COM26 的 `motor_test` 多次读到 AW86233 CHIPID `0x2330`，启动后 `GLB_STATE=0x06`（CONT），随后 STOP 成功。`logs/motor_scope_single_20261012.log` 保存一次完整记录。
- 用户示波器照片 `logs/motor_scope_outputs_20261012.jpg`：黄色 CH1 接 `MOT+`，蓝色 CH2 接 `MOT-`，两只地夹均接板上 GND；两焊盘各自对地均出现周期性波形。尚未测得 `CH1−CH2` 差分幅值，也没有测得电机电流。
- 用户未感到马达振动。现有测试只输出约 170 Hz、120 ms、低幅度的 CONT 交变波形，原本用于 LRA 类负载；它不能作为 ERM 是否能旋转的验收。用户表示已确认马达本体正常，但本轮没有独立直流供电实测记录。

## 必须修改的信号连接（若采用原厂 PWM_ERM 模式）

| 端点 | 当前设计/作用 | 修改建议 |
|---|---|---|
| AW86233 U8 pin7 `PWM/TRIG1` | 用户提供的原理图局部显示该脚未连到 GR5526 | 增加从 GR5526 **硬件 PWM 输出**到 U8 pin7 的专用信号线；马达仍接 `MOT+`/`MOT-`，不要接 MCU PWM 引脚 |
| 候选 GR5526 GPIO16 / QFN68 pin46 | 原理图未引出该脚；SDK 支持 `GPIO1_PIN0_MUX_PWM0_C = GPIO_MUX_5` | 可作为 PWM0_C 候选。改板前核对实际 PCB 焊盘/过孔、无其他连接和固件占用；样板飞线优先找可焊接的可达点，量产 PCB 应正式布线 |
| U8 pin7 上电默认 | AW86233 内有约 2 MΩ 下拉 | 修订 PCB 时可预留对地外部下拉与串联调试电阻位，以确保上电/复位阶段 PWM 输入保持低；具体阻值须按布局及信号完整性确认 |

原厂 `DS_AW8623X_EN_V1.4` 第25页规定：`0x45` 寄存器的 `TRG1_MODE[6:4]=001` 选择 `PWM_ERM`，U8 pin7 输入频率 **24–250 kHz**。原厂电气表给出相关逻辑输入高电平门限约 **0.8 V**；GR5526 本板 1.8 V GPIO 输出在电平上可满足，接线后仍需测 U8 pin7 实际高/低电平和 PWM 频率。PWM 播放期间原厂要求不要配置 I²C。

**不要改接 GPIO26、GPIO27、GPIO11 或 GPIO12。**GPIO26 控制马达电源开关，GPIO27 控制 U8 复位，GPIO11/12 已用于 I²C3。GPIO16 只是经原理图和 SDK 静态核对的候选，尚未在实板确认可焊接位置。

## 电源与额定电压

U8 VDD_MOT 在测试时曾测约 **4.17 V**，高于 ERM 额定 **3.3 V**。32 Ω 在 3.3 V 下的静态电流估算约 **103 mA**，不是实测启动电流。PWM_ERM 固件必须限制驱动，并以马达两端差分电压/电流和温升验证；不能让 PWM 长时间满占空比。若量产要求无论固件失控都不超过马达额定电压，应评估给 U8 提供独立、足够电流能力的 3.3 V 电源，或改用适配电池电压的马达；不能未经核对直接占用板上已有 1.8 V/3.3 V 小负载电源。

具体有两种供电策略：

1. **样板先保留 VCC_SYS→Q1→R45→VDD_MOT。**AW86233 的 VDD 允许范围是2.7–5.5V，所以约4.17V对芯片本身是允许的；但马达额定3.3V，必须从保守 PWM 设置开始，实测马达两端差分电压、实际电流、温升，并覆盖 VCC_SYS 最大/最小值。输入 PWM 占空比不是马达端电压的直接标尺；不能简单把占空比设为 `3.3/VCC_SYS≈79%`。即使把输出近似成直接开关的4.17V脉冲，79%对应的电压均方根约3.71V而非3.3V；实际 AW86233 PWM_ERM 传递关系须以原厂资料及实测为准。该方案依赖固件限幅，不能提供硬件级3.3V上限。
2. **量产优先评估专用3.3V马达供电。**把驱动芯片 VDD_MOT 改由具有足够峰值电流能力的3.3V稳压电源供电，并保留可控上电/断电；先量出 VCC_SYS 的全工况范围。如果 VCC_SYS 可能低于3.3V加 LDO 压差，普通3.3V LDO不能全程稳压，应选合适的升降压方案或重新定义低电量振动性能。可以规划 `VCC_SYS→专用3.3V稳压/受控开关→VDD_MOT`；改线时必须断开现有 `Q1→R45(0Ω)→VDD_MOT` 的电池直通支路，不能把稳压器3.3V输出与原4.17V支路并在一起。若保留 Q1，应重新核算其在稳压器前/后的位置、压降、启动浪涌和控制逻辑。现有 U4 3.3V 电源已服务其他电路，未核对余量前不得直接把 VDD_MOT 并到其输出。即使供电稳为3.3V，也仍需量测实际马达电流和温升。

## 固件配套与改后验收

接线本身不会使现有 `motor_test` 变成 ERM 测试。改线后需在主工程及交付副本同步新增受限的 PWM_ERM 测试：先保持 PWM 低并上电/复位 U8，核对 CHIPID/故障，再设置 `TRG1_MODE`；随后输出硬件 PWM，按低占空比起步，限定时长，停止时先拉低 PWM，再断复位/电源。保留现有 `motor_probe` 和 LRA CONT 命令供诊断，不混称 ERM 功能通过。修改代码时按项目 `AGENTS.md` 填写北京时间/SAM 注释、中文修改说明和强制检查项，重新编译两份 Keil 工程并由用户下载。

实现入口可用 SDK `app_pwm`，把 PWM0 的 C 通道复用到 GPIO16/QFN46（`GPIO1_PIN0_MUX_PWM0_C`），选择原厂允许区间内的频率（例如48kHz），停止电平为低；保留 GPIO26 电源、GPIO27 复位和 I²C3。初始化阶段读改写 U8 `0x45` 的 `TRG1_MODE[6:4]` 为 `001`，不得覆盖其他位；PWM 播放期间不做 I²C 配置。测试命令限制最大占空比和持续时间，任何故障、超时或退出都先停 PWM 并确认引脚低，再复位/断电；从示波器差分波形和电流实测校准占空比，不能仅由输入占空比推算马达电压。未改线时该命令不能做真实 ERM 功能验收。

改后实板依次验收：U8 pin7 的 PWM 电平/频率；U8 VDD_MOT 在负载下保持正常；`MOT+−MOT-` 差分驱动及电流不超过马达规格；马达实际起转/停止；重复触发和异常停止后无卡住、过热或故障位。编译、串口状态和示波器波形不能替代实际转动验收。

## 暂未采用的替代路径

AW86233 也支持经 I²C 的 RAM/RTP 波形播放，可进一步研究是否能用受限的单向 ERM 波形避免改线；但当前 I²C3 为 100 kHz，而原厂 12 kHz RTP 表要求至少 250 kHz，不能直接套用仓库旧 RTP 正弦示例。未验证该路径可让本马达起转，不能据此取消 PWM 接线需求。

## 后续全新电路设计建议（仅使用单向 ERM 的场景）

若产品目标只是报警时让一颗3.3V偏心旋转马达起转/停止，并不需要线性振子、波形库、闭环共振跟踪或驱动芯片故障诊断，则**新板建议取消 AW86233**。推荐结构为：

`VCC_SYS → 专用3.3V稳压电源 → ERM正端；ERM负端 → 低边N-MOS漏极；N-MOS源极 → GND；GR5526硬件PWM → 栅极`。

关键选型/连接条件：低边 MOSFET 的导通电阻必须在 **VGS=1.8V** 条件下有明确保证，因为 GR5526 GPIO 为1.8V域；选型要留电机堵转/浪涌余量，不能仅按32Ω算出的约103mA选最小额定电流。栅极预留小串联电阻和下拉电阻，使 MCU 复位期间保持关断。电机两端增加续流二极管（阴极接3.3V正端、阳极接 MOSFET 漏极/电机负端），并按实测补充电源去耦/EMI抑制。若 VCC_SYS 可能低于3.3V加压差，要采用可覆盖电池全范围的升降压3.3V方案，不能简单选LDO；若低电量时允许振动减弱，可重新定义电源规格。PWM 可选高于人耳可闻范围的频率起步，再据电流、噪声、温升和转速调校，软件仍需最长运行时间、故障关断及电池低压约束。

如果未来要兼容 **LRA 与 ERM**、多种精细触觉波形、内建保护/检测且接受额外BOM与软件复杂度，则可保留 AW86233；新板必须把 PWM/TRIG1 接到 MCU，重新评估马达供电和波形/占空比。上述简化方案与保留方案二选一，不能在同一马达两端同时并联 MOSFET 驱动和 AW86233 HDP/HDN。
