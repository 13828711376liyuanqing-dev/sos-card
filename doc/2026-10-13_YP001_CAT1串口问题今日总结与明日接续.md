# 2026-10-13 YP001 GR5526 ↔ Air780EGH 串口问题总结

## 今天要解决的问题

GR5526 通过 UART4 向 Air780EGH UART1 发送命令，GR 报告发送成功，但 CAT1 仅偶尔正确回复；`BUS_CMD` 和 `AT+ANTSTATUS` 会出现字符变形。用户要求用 J-Link、COM26、DL32 继续定位，不再把 R21 这个 0Ω 电阻的两端比较当作主要工作。CAT1 源码唯一入口是 `D:\CODEX\sos-card\Air780EGH`。

## 已确认的事实

1. **供电/静态电平**：用户实测 GR5526 VDDIO_0、AON_GPIO2/UART4_TX 空闲高电平约 3.3V；CAT1 UART1_TXD、VDD_EXT 也约 3.3V。未见静态 1.8V/3.3V 不匹配的证据，但万用表读数不能证明动态波形质量或器件引脚绝对额定值。
2. **GR UART 配置**：J-Link V9 只读 VTref 3.330V、UART4 LCR=`0x00000003`（8N1）、DLF=0；无 reset/halt/flash。源码将 AON_GPIO2 配为 UART4 TX、MUX0、`APP_IO_NOPULL`，CAT Lua 源码设 `uart.setup(1, 460800, 8, 1)`。`APP_IO_MODE_MUX` 和 `NOPULL` **并不直接证明 TX 焊盘已按推挽方式驱动**；需结合 GR5526/Air780EGH 厂商文档、实际运行寄存器及波形确认。
3. **同步证据**：19:38:53 DL32 以 10MHz 在用户确认的 CAT1 第 17 脚 UART1_RXD 采集。10 秒窗内 22 条 14 字节测试命令，11 条严格正确、11 条变形；例如 DL32 解出的 `AT+ANTRTATUS`、`AT+ANTST@TTS`、`@T*@NTSTATUS` 与同期 CAT USB 日志中的命令逐字一致。因此 CAT1 实际收到错误字节，不是 Luatools 显示或 Lua 命令分派单独造成的。
4. **错误模式**：以 bit0 被清零为主，如 `A→@`、`+→*`、`S→R`、`\r→\f`。正确 `A` 的起始低位约 21 个 10MHz 样本、bit0 高约 22 个；错误 `@` 在起始位与 bit0–bit5 连续低约 151–152 个样本，同字节后续高位仍有约 21–22 个样本。只能确定在 DL32 1.6V 阈值处看不到预期 bit0 高脉冲；尚不能断言是 GR 发送数据错误还是起始位后的波形未跨 CAT 输入门限。
5. **端到端结果**：USB 日志恢复后，12 条 `AT+ANTSTATUS` 均有 GR `[CAT1 TX] ok=1 bytes=14`，但只看到 2 条成功 STATUS ACK、1 条 BAD_ARGS；其余对应多条 CAT “未知命令”变形记录。发送 API 成功不等于 CAT 正确接收。CAT USB 日志口曾于 17:33 断开，19:30 左右重新枚举 COM21/22/23；COM26 始终为 GR 调试串口。
6. **版本独立问题**：CAT 日志把完整 `BUS_CMD=...` 也记为“未知命令”，而当前 `Air780EGH/uart_app.lua` 已有该命令分派。运行脚本与工作区当前源码不一致，明天须核对 Luatools 项目文件清单和设备实际脚本；这不能解释 UART 线上字节本身的变形。

## 今天的尝试与纠正

- 早期 DL32 抓取曾错过发送窗口；之后用持续 COM26 发送和 F1 完成了真正同步的 CAT USB/DL32 同帧对照。不能把未同步的两轮写成波形证据，也不能仅凭时间将一条 `BAD_ARGS` 配给某条错误命令。
- GR 曾单端临时改为 115200，DL32 证实位宽随之变化；**CAT Lua 当时仍是 460800**，所以该轮不能评价双方同降速后的通信效果。GR 已恢复 460800。
- 今日没有改固件、烧写、擦除或更改用户数据。此前提出的 10 kΩ 到 CAT1 `VDD_EXT` 临时上拉**没有安装，也没有测试结果**；用户决定今天停止，明天继续。

## 关于“3.3V 直连、两端推挽”的明日核对

用户提出：3.3V 串口可以直连，但两端要设置推挽输出。将其作为优先核对的工程假设，**不把它写成今日已验证的根因或修复**。UART 连接中是两端的 **TX 输出**分别核对推挽驱动、输出电平域和管脚复用；两端的 **RX 为输入**，不能配置为推挽输出。还需按两款器件的 UART 引脚电压额定值确认直连条件。GR 当前 SDK 的 UART 初始化只显式设置 MUX/上拉，未在该路径看到推挽选择字段；明天需查实际硬件寄存器或厂商说明，而非凭空改配置。

## 明天从这里继续

1. 先保持板子现状，确认 CAT USB 日志、COM26、DL32 可用；不要先安装 10 kΩ 或重刷固件。
