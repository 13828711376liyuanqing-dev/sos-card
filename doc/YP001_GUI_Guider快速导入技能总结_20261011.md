# YP001 GUI Guider / LVGL 快速导入技能

这份记录把本轮调试沉淀成后续可复用流程：GUI Guider 负责设计和生成，项目脚本负责适配，Keil 工程负责编译，交付工具负责同步。不要把 GUI Guider 源目录误当成 Keil 直接输入目录。

## 1. 在 GUI Guider 中生成

打开：

```text
D:\CODEX\sos-card\LVGL\YP001\YP001.guiguider
```

生成前确认页面数量和资源数量分开统计。本项目是 6 个页面（`screen`、`screen_main`、`screen_time`、`screen_lowbat`、`screen_calling`、`screen_callend`）和 5 个图片资源。按 `Ctrl+G` 生成，等待日志出现 `Code generation completed`，确认以下文件存在：

```text
LVGL\YP001\generated\setup_scr_*.c
LVGL\YP001\generated\gui_guider.c/h
LVGL\YP001\generated\guider_fonts\
LVGL\YP001\generated\guider_customer_fonts\
LVGL\YP001\generated\images\
```

如果生成停在字体或代码阶段，先检查字体族引用是否是工程已注册的 `simhei`；字号由 16/24/28/32/40 独立设置。不要先用旧缓存覆盖磁盘工程。

## 2. 一条命令导入到两个 Keil 工程

GUI 生成成功后，在仓库根目录运行：

```powershell
& 'C:\Users\SamLi\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' tools\import_guider_ui.py
```

脚本会从 `LVGL\YP001\generated` 读取 6 个页面、5 个图片和字体源，导入到：

```text
ble_app_uart_c\Src\user\gui\guider\
SVN交付_YP001_GR5526_20261001\ble_app_uart_c\Src\user\gui\guider\
```

它还会完成已验证的 1bpp 字体行补齐、字体符号映射和二维码边界适配，并生成 `doc\YP001_GUI_Guider导入清单_20261011.json`。重复导入前会拒绝主工程和交付副本存在独立差异的情况，避免静默覆盖。

GUI Guider 自带的 `LVGL\YP001\lvgl` 不替换目标工程的 `Src\external\lvgl_8.3.1`。Keil 应继续引用 `..\Src\external\lvgl_8.3.1` 和 `..\Src\user\gui\guider`。

## 3. 主机验证和 Keil 编译

先执行主机测试：

```powershell
& 'C:\Users\SamLi\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' tools\test_guider_ui.py
```

然后分别编译：

```powershell
& 'C:\Keil_v5\UV4\UV4.exe' -b 'D:\CODEX\sos-card\ble_app_uart_c\Keil_6\YP001_GR5526.uvprojx' -t YP001_GR5526_AC6 -o 'D:\CODEX\sos-card\logs\gui_guider_main_latest.log'
& 'C:\Keil_v5\UV4\UV4.exe' -b 'D:\CODEX\sos-card\SVN交付_YP001_GR5526_20261001\ble_app_uart_c\Keil_6\YP001_GR5526.uvprojx' -t YP001_GR5526_AC6 -o 'D:\CODEX\sos-card\logs\gui_guider_delivery_latest.log'
```

两份日志必须分别确认 `0 Error(s), 0 Warning(s)`，并确认新 AXF/HEX 的时间晚于本轮源码修改。旧 AXF/HEX 不能作为新源码编译证据。

## 4. 同步交付文件夹

同步工具不是实时监视器。每次 GUI 重新生成、导入或新增 Keil 输入后，先预览：

```powershell
& 'D:\CODEX\sos-card\YP001_交付同步工具\Invoke-YP001Delivery.ps1'
```

确认 `main -> delivery ADD/UPDATE` 后，再按项目约定运行：

```text
D:\CODEX\sos-card\YP001_交付同步工具\运行_检查清理同步.cmd
```

工具同步 `ble_app_uart_c\Src`、Keil/GCC 输入、SDK 输入和 Keil 直接引用，并把内容复制到 `D:\SVN`；不会实时自动同步，也不会把 GUI Guider 源目录直接放进 Keil。清理只允许 Objects/Listings 白名单中间文件，AXF/HEX、工程、散装脚本和下载配置必须保留。

## 5. 下载和页面切换验收

烧录本轮重新生成的：

```text
ble_app_uart_c\Keil_6\Objects\YP001_GR5526.hex
```

通过汇顶 UART0（当前实测 115200 8N1，命令以 CR 结束）发送：

```text
epd_page screen
epd_page screen_main
epd_page screen_time
epd_page screen_lowbat
epd_page screen_calling
epd_page screen_callend
```

可双击 `tools\启动页面切换上位机.bat` 发送页面命令。串口回显、下载 Verify、主机预览和 e-paper 实际像素分别记录；前三者不能替代最后一项。

## 6. 必须保留的边界

- 页面切换命令只选择模板，不自动拨号、挂断、报警或改变充电。
- GUI Guider 示例 IMEI、二维码、姓名、房间、时间、电量和呼叫文案没有自动变成实时业务数据；绑定属于后续开发。
- 不改 `epaper_lvgl.c` 的已验证 flush 和显示驱动注册参数，不改变 1bpp 配置、24KB 内存池、Flash/scatter/download 基线。
- 每轮在 `doc` 写中文修改说明；代码附近写 `SAM | 北京时间 | 修改内容及原因`；实板通过只在有实际串口/显示证据时记录。
