## 厂商 API 核对结果

官方来源：`https://github.com/openLuat/LuatOS`，路径 `luat/modules/luat_lib_crypto.c`、`luat/modules/luat_lib_fota.c`、`components/rsa/binding/luat_lib_rsa.c`、`components/network/libhttp/luat_lib_http.c`。

- crypto.hash_update 没有返回值，不能要求其直接返回 true；绑定层捕获异常并接受正常 nil 返回，最终摘要仍必须相符。
- rsa.verify 接受 PEM、公钥算法常量、二进制摘要和二进制签名。用 HEX 字符串直接传摘要会错误。
- fota.file 内部调用 luat_fota_done 后继续 luat_fota_end(1)，不能当作仅写入且不提交的预置接口。本轮没有调用 fota.init/run/file/finish，也没有重启设备。
- 核对到的 http.request API 没有已确认的接收体硬上限参数。仅发送 Range 不保证对端只回少量数据，旧平台就曾忽略 Range。不能把下载完再检查长度当作接收期间限长，生产网络适配仍需解决。
