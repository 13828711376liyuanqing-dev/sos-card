# 方案 1：暗室仪器直接控制 YP001 蓝牙 DTM

适用：天线厂的蓝牙测试仪可以通过 UART/HCI H4 直接控制 DUT，例如能在仪器软件中配置 DUT COM 口并执行 BLE DTM TX/RX。此方案无需运行本项目的电脑手动控制工具；仪器软件和暗室设备由天线厂提供，当前尚未知具体型号，无法将其厂商软件打包或预设仪器菜单。

## 本文件夹内容

- `固件/YP001_BLE_DTM_TEST.hex`、`.bin`：**仅用于 GR5526 测试**的候选镜像，已由 GNU Arm GCC 编译，尚未实板运行验证。优先使用带地址的 HEX；裸 BIN 的装载地址为 `0x00202000`。
- `HCI命令参考.md`：仪器支持原始 H4 命令时可核对 TX/RX/停止命令。
- `SHA256SUMS.txt`：交付文件校验值。

烧写仍需天线厂或研发现场**已有且已验证适配 GR5526 的 J-Link/GR5xxx 烧写器及驱动**；暗室仪器的软件、驱动和设备由仪器厂商提供。这些第三方程序依赖具体型号和授权，不能把一个未知仪器的软件当作本包可执行文件。已生成的固件不需再用 Keil 编译。

## 方案 1 需要的软件与核对条件

| 软件/驱动 | 提供方 | 必须确认的能力 |
|---|---|---|
| 蓝牙 RF/OTA 测试软件及对应仪器驱动 | 暗室仪器厂商 | 能测 BLE 1 Mbps 的 TX 与 RX，并保存仪器结果；若测 TRP/TIS，还需该暗室的转台、校准与报告功能 |
| 仪器的 DUT 控制模块或授权选件 | 暗室仪器厂商 | 能打开连接 YP001 的串口，以 HCI H4 向 DUT 发送 Reset、LE TX Test、LE RX Test、LE Test End 并读取回执；串口可设 115200/8N1/无流控 |
| USB 转串口驱动 | 串口适配器厂商 | 电脑或仪器软件能识别连接 YP001 UART0 的 COM 口；若仪器直接提供 DUT UART 口，按其手册接线 |
| GR5526 烧写软件及 J-Link/GR5xxx 驱动 | 现场现有烧写工位 | 能按 HEX 中地址写入并校验**指定应用区**，确认实际擦除范围不触及 NVDS/身份数据；测试后能恢复原产品镜像 |

本方案**不用**汇顶 DTMTool 或本项目的 `YP001_BLE_DTM_手动工具.exe` 来控制 DUT；让两套软件同时打开 DUT 串口会冲突。若仪器软件只有 RF 测量、没有上述 HCI DUT 控制功能，则不满足方案 1，改用方案 2。仪器品牌/型号、软件版本和 DUT 控制选件尚未提供，当前不能判定天线厂现有设备已经满足本表。

## 操作顺序

1. 核对板号并备份**当前板上确切的产品固件镜像**及版本；若无可靠恢复方式，仅在专用工程样机上试烧。测试固件与产品固件不能同时运行，烧入测试镜像会暂时替代产品程序。本目录不包含产品固件，也不会修改仓库中的产品工程。
2. 用现场已验证的 GR5526 烧写设备将 `固件/YP001_BLE_DTM_TEST.hex` 写入 GR5526 应用区域。写入前在烧写器中确认目标板、起始地址、实际擦除范围，选择应用区擦除并执行写后校验；不要执行“整片擦除”或改变 NVDS/身份区。这里不附自动烧写脚本，以免对未知板号和烧写器实施错误擦除。无需用户再使用 Keil 编译。
3. 将已验证的 YP001 UART0 接到仪器的 DUT 控制串口：GR5526 GPIO28 TX→仪器 RX、GPIO29 RX←仪器 TX，双方共地；115200、8 数据位、无校验、1 停止位、无流控。复用现有已验证电平适配器，确认实际 I/O 电平，勿把 5 V 直接施加到 MCU 引脚。
4. 暗室按天线厂 OTA 夹具固定板姿态与供电；仪器 RF 端通过暗室天线与 YP001 空间耦合。传导电缆测试不等于整板天线 OTA 结果。
5. 在仪器软件中选 HCI H4 控制与上述 COM 参数，先发 HCI Reset 并确认成功。再分别跑低/中/高 DTM 信道的 TX，读取仪器辐射功率、频偏、调制和其支持的方向图/TRP；每次结束确认 DUT 停止发射。
6. 再跑相应信道的 RX：仪器发送已知功率、已知包数的测试包，DUT 在 Test End 回报正确接收包数；由仪器按自身校准流程计算 PER、灵敏度及可用的 TIS。不要把 DUT 收包数叫作 RSSI。
7. 保存仪器报告、板号、镜像哈希、信道、输出功率、夹具与校准记录。测试结束复位板端并恢复确切产品镜像，再核对产品版本、BLE 广播和业务。恢复结果需实板记录。

## 判定边界

当前未取得天线厂仪器型号、控制协议、暗室校准值和合格阈值，因此本包不能自动给出 PASS/FAIL。仪器若不能直接发送 HCI H4，请改用独立的 `方案2_电脑手动控制`；两种控制端不能同时占用 DUT 的同一串口。首次烧写后必须先验证 Reset/TX/RX/End 均有有效 HCI 回执，再做正式 RF 测量。
