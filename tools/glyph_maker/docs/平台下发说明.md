# 姓名字形平台下发包（2026-11-02）

**一个姓名 = 一个文件**（`residentNameMsg_<姓名>.json`）。平台只需要处理这个文件。

## 方式一（推荐，和 OTA 一样）：上传文件，下发地址

1. 把 `residentNameMsg_<姓名>.json` 上传到平台文件存储，拿到下载地址（**只用 JSON，不要压缩包**）。
2. 向终端下行主题 `/iotplat/render3/WARNCARD3/<IMEI>/down_raw` 发一条短消息：

```json
{"MsgType":"residentNameUrl","Url":"http://…/residentNameMsg_张秀华.json","Md5":"<文件 MD5，可选但建议带>"}
```

3. 终端（CAT1）先清理自己的日志文件（腾出空间），再自己下载、校验 MD5、转给屏幕显示。

## 方式二：直接把文件内容作为 MQTT 消息下发

文件内容本身就是一条完整消息（`MsgType=residentNameMsg`），原样发到同一个下行主题即可。

## 终端回执（上行主题 `/iotplat/datapush3/notsos/WARNCARD3/<IMEI>`）

- `{"MsgType":"residentNameReply","Seq":…,"Result":"ok"}`：已显示
- `Result`=`download`（`Err` 为 `HTTP_404`/`MD5`/`SIZE_…`/`NOT_RESIDENT_NAME_JSON`）：下载或校验失败
- `Result`=`fail`/`bad`/`stale`：转屏幕失败、格式不对、Seq 比上一条旧
- 终端重启后缺字会发 `{"MsgType":"residentNameNeed","Missing":[…]}`，平台再下发一次即可。

## 注意

- 同一终端 `Seq` 递增（文件里已带，生成工具默认用当前时间）。
- 生成新姓名：后台用 `tools/glyph_maker/backend/姓名字形生成器_后台版.html`。
- 终端 CAT1 需刷 `firmware_releases/name_push_cat1_20261102/out/USB_IMPORT`（1.5.8/b12，不升版本）。
